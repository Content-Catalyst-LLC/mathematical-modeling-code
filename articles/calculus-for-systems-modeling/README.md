# Calculus for Systems Modeling

This article folder supports reproducible examples for calculus-based systems modeling.

## Topics

- continuous change
- derivatives and rates of change
- integrals and accumulation
- flow-to-stock reasoning
- numerical differentiation
- numerical integration
- differential equations
- Euler simulation
- sensitivity analysis
- parameter sweeps
- responsible model interpretation

## Folder Structure

- `python/` — numerical calculus and dynamic simulation
- `r/` — simulation, visualization, and sensitivity analysis
- `julia/` — scientific-computing examples
- `sql/` — model metadata and simulation records
- `c/`, `cpp/`, `fortran/`, `rust/`, `go/` — compact numerical examples
- `docs/` — modeling notes
- `data/` — synthetic input data
- `outputs/` — generated outputs
- `notebooks/` — notebook placeholders
