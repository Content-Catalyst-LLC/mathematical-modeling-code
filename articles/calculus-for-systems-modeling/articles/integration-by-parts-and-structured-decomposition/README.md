# Integration by Parts and Structured Decomposition

Companion code and reproducible workflows for **Integration by Parts and Structured Decomposition** in the **Calculus for Systems Modeling** series.

## Themes

- integration by parts as product-rule decomposition;
- boundary terms and endpoint interpretation;
- residual accumulated interaction;
- choice of parts as an interpretive decision;
- weighted accumulation;
- repeated decomposition;
- unit consistency;
- direct-versus-decomposed residuals;
- structured audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A useful integration-by-parts decomposition should report direct accumulation, boundary contribution, residual accumulation, decomposition residual, units, interval, numerical method, and interpretive purpose.
