# Scaling, Units, and Nondimensionalization Notes

Scaling, units, and nondimensionalization connect dimensional analysis, unit systems, reference scales, nondimensional variables, dimensionless parameters, similarity solutions, asymptotic reasoning, numerical conditioning, perturbation methods, and model governance.

## Required distinctions

- unit record versus raw value
- reference scale versus empirical truth
- dimensionless variable versus validated result
- scaling law versus mechanism
- numerical conditioning versus model correctness
- dimensional consistency versus empirical validity
- nondimensional form versus responsible interpretation

## Review checklist

- Document units for every variable, parameter, data column, solver setting, axis, and output.
- Validate unit compatibility before computation.
- Record conversion rules and reference scales.
- Export dimensional and nondimensional values.
- Attach warnings to scaled or normalized interpretations.
- Preserve parameter ranges, tested domains, and claim boundaries.
