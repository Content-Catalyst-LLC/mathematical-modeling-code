# Stability, Error, and Convergence in Numerical Modeling

Companion code and reproducible workflows for **Stability, Error, and Convergence in Numerical Modeling** in the **Calculus for Systems Modeling** series.

## Themes

- local and global error
- truncation and round-off error
- consistency, stability, and convergence
- step-size refinement
- solver diagnostics
- RK4 benchmark comparisons
- stability warnings
- numerical reliability governance
- reproducible computational audits
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
