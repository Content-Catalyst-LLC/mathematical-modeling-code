# Advanced Layer: Domains, Ranges, and the Structure of Functional Models

This advanced layer upgrades the companion workflow for **Domains, Ranges, and the Structure of Functional Models** so it is more credible for mathematicians, applied mathematicians, numerical analysts, and mathematically mature systems modelers.

## Focus

domains, codomains, images, feasible sets, invariant sets, constraints, and state spaces

## What this layer adds

- formal definitions and modeling distinctions;
- proposition/counterexample/boundary-case HTML template;
- forward and central difference comparison;
- Richardson extrapolation;
- convergence-order estimation;
- roundoff-window review;
- invariant/domain-preservation checks;
- generated Markdown and JSON audit reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```
