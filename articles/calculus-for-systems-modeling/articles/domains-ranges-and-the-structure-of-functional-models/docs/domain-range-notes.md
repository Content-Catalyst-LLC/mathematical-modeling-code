# Domain and Range Notes

Domains and ranges define where functional models are valid and what their outputs can mean.

Review questions:
- Which input values are mathematically allowed?
- Which input values are empirically supported?
- Which input values are physically or institutionally feasible?
- Which outputs are meaningful?
- Which outputs should trigger review?
- Which scenarios are interpolation, extrapolation, or stress tests?

A model output should not be interpreted merely because it was computed.
