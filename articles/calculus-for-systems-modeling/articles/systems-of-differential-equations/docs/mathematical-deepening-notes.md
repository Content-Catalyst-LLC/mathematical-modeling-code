# Mathematical Deepening Notes

## Required distinctions

- scalar differential equation versus vector differential equation
- state variable versus state vector
- uncoupled system versus coupled system
- autonomous system versus nonautonomous system
- linear system versus nonlinear system
- equilibrium point versus trajectory
- phase-plane pattern versus time-series plot
- local stability versus global behavior
- numerical simulation versus model validity
- domain constraints versus unrestricted state space

## Review checklist

- Define each state variable and its unit.
- Explain each coupling term.
- Document initial conditions for every state.
- Record parameter meanings, units, sources, and uncertainty.
- Identify equilibria and stability where appropriate.
- Document solver method, time horizon, step size, and tolerances.
- Check whether state variables remain within meaningful domains.
- Explain whether the model is descriptive, mechanistic, exploratory, scenario-based, or predictive.
