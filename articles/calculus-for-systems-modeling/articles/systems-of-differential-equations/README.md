# Systems of Differential Equations

Companion code and reproducible workflows for **Systems of Differential Equations** in the **Calculus for Systems Modeling** series.

## Themes

- state vectors
- coupled equations
- autonomous and nonautonomous systems
- linear and nonlinear systems
- equilibrium points
- stability and local behavior
- phase planes
- matrix form
- predator-prey dynamics
- numerical simulation
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
