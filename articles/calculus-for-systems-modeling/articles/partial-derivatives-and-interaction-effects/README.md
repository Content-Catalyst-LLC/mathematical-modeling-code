# Partial Derivatives and Interaction Effects

Companion code and reproducible workflows for **Partial Derivatives and Interaction Effects** in the **Calculus for Systems Modeling** series.

## Themes

- partial derivatives as local sensitivity measures
- fixed-variable assumptions
- interaction terms
- cross-partial derivatives
- feasible-region checks
- local reference states
- analytic and numerical sensitivity
- derivative grids and interaction diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
