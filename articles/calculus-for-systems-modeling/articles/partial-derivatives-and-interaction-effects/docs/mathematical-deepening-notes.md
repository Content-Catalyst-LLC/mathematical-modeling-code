# Mathematical Deepening Notes

## Required distinctions

- partial derivative versus total derivative
- coordinate slice versus feasible system path
- analytic derivative versus numerical derivative
- fixed-variable assumption versus coupled input change
- interaction term versus additive structure
- cross partial versus causal interaction
- local sensitivity versus global effect
- derivative value versus intervention leverage

## Review checklist

- State the function.
- Define each input and unit.
- State the reference point.
- State which variables are held fixed.
- Identify interaction terms and cross partials.
- Check feasible-region constraints.
- Distinguish local mathematical sensitivity from practical system intervention.
