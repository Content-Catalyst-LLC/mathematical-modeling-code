# Related Rates and Interdependent Motion

Companion code and reproducible workflows for **Related Rates and Interdependent Motion** in the **Calculus for Systems Modeling** series.

## Themes

- related rates as interdependent motion;
- time-dependent variables;
- chain rule rate propagation;
- implicit-rate coupling;
- tangent-space interpretation;
- reservoir-style state-rate conversion;
- unit and operating-point review;
- finite-difference checks;
- noisy rate warnings;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A related-rates claim is meaningful only when the system relationship, driving rate, operating point, units, and conditioning are documented.
