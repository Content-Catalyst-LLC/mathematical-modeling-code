# When Continuous Models Mislead

Companion code and reproducible workflows for **When Continuous Models Mislead** in the **Calculus for Systems Modeling** series.

## Themes

- false smoothness
- hidden thresholds and structural breaks
- equilibrium bias
- aggregation and heterogeneity risk
- extrapolation and domain drift
- parameter fragility
- solver artifacts
- missing mechanisms
- institutional and social discontinuities
- SQL governance registries
- Haskell typed misuse records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
