# Improper Integrals and Unbounded Quantities

Companion code and reproducible workflows for **Improper Integrals and Unbounded Quantities** in the **Calculus for Systems Modeling** series.

## Themes

- improper integrals as limit-defined accumulation;
- infinite intervals and long horizons;
- unbounded integrands and singular endpoints;
- convergence and divergence;
- tail behavior and comparison reasoning;
- threshold and critical-boundary interpretation;
- numerical truncation and cutoff sensitivity;
- model validity near unbounded domains;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A responsible improper-integral workflow should state the limiting process, convergence evidence, truncation cutoffs, tail estimates, unit meaning, numerical sensitivity, and model-validity boundary.
