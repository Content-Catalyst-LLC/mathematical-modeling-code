# Mathematical Deepening Notes

## Required distinctions

- deterministic versus predictable
- chaotic behavior versus random noise
- sensitivity to initial conditions versus ordinary instability
- nonlinear map versus continuous flow
- short-horizon usefulness versus long-term point prediction
- attractor structure versus visual irregularity
- transient behavior versus long-run behavior
- Lyapunov estimate versus proof of chaos
- numerical precision versus system dynamics
- forecast horizon versus model validity

## Review checklist

- Define the model equation and state variable.
- Document initial conditions and perturbation sizes.
- Record parameter values, iteration counts, and burn-in choices.
- Save trajectory divergence tables, not only plots.
- Estimate sensitivity with documented methods.
- Compare perturbation sizes, parameter values, and numerical precision.
- Distinguish deterministic sensitivity from random noise.
- Communicate forecast horizons and uncertainty honestly.
