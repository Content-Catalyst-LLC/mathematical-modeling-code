# Chaos and Sensitivity to Initial Conditions

Companion code and reproducible workflows for **Chaos and Sensitivity to Initial Conditions** in the **Calculus for Systems Modeling** series.

## Themes

- deterministic unpredictability
- sensitivity to initial conditions
- nonlinear amplification
- phase-space trajectories
- attractors
- logistic map iteration
- Lyapunov exponents
- forecast horizons
- numerical precision
- initial-condition divergence
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
