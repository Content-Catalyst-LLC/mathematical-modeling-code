# Surface Integrals and Distributed Accumulation

Companion code and reproducible workflows for **Surface Integrals and Distributed Accumulation** in the **Calculus for Systems Modeling** series.

## Themes

- scalar surface integrals
- vector surface integrals
- flux through oriented surfaces
- surface parameterization
- tangent vectors and normal vectors
- surface-area elements
- distributed accumulation
- mesh and patch approximation
- boundary interpretation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
