# Case Study: Climate Feedback Models

Advanced companion code and reproducible workflows for **Case Study: Climate Feedback Models** in the **Calculus for Systems Modeling** series.

## Themes

- one-box energy balance models
- two-box ocean heat uptake models
- radiative forcing
- feedback parameters and sign conventions
- Planck response and stabilizing feedback
- water vapor, cloud, albedo, and carbon-cycle feedbacks
- equilibrium climate sensitivity
- transient climate response
- heat capacity and time-scale separation
- threshold and tipping-risk notes
- calibration and identifiability diagnostics
- SQL governance registries
- Haskell typed climate records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
