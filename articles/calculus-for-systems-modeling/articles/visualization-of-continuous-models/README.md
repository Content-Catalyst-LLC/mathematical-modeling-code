# Visualization of Continuous Models

Companion code and reproducible workflows for **Visualization of Continuous Models** in the **Calculus for Systems Modeling** series.

## Themes

- trajectory plots
- phase portraits and state space
- slope fields and vector fields
- surfaces and contour plots
- uncertainty bands and scenarios
- sensitivity displays
- diagnostic plots
- visual metadata and figure governance
- reproducible graphics workflows
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
