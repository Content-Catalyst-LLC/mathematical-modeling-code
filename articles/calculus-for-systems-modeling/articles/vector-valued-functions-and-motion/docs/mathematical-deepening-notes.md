# Mathematical Deepening Notes

## Required distinctions

- vector-valued function versus scalar component functions
- position vector versus trajectory image
- parameterized curve versus geometric curve
- velocity versus speed
- acceleration from speed change versus acceleration from direction change
- arc length versus displacement
- physical trajectory versus state-space trajectory
- continuous path versus sampled computational path
- time step versus model time scale
- state-space scaling versus physical distance

## Review checklist

- State the parameter and its units.
- Define each component function.
- State coordinate system, projection, or state-space basis.
- Document parameter interval.
- Distinguish distance traveled from displacement.
- Report sampling resolution and finite-difference method.
- Explain smoothing or interpolation.
- Identify stationary points and missing observations.
- When working in state space, document scaling and normalization.
