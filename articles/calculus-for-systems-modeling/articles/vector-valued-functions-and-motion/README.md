# Vector-Valued Functions and Motion

Companion code and reproducible workflows for **Vector-Valued Functions and Motion** in the **Calculus for Systems Modeling** series.

## Themes

- vector-valued functions
- parameterized curves
- position vectors
- velocity and acceleration
- speed and direction
- arc length and distance traveled
- displacement and path efficiency
- curvature and turning
- state-space trajectories
- computational sampling and finite differences
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
