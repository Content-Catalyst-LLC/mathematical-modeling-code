# Interpretation, Assumptions, and Responsible Mathematical Modeling

Companion code and reproducible workflows for **Interpretation, Assumptions, and Responsible Mathematical Modeling** in the **Calculus for Systems Modeling** series.

## Themes

- model purpose and claim type
- assumption records
- parameter evidence and meaning
- scope boundaries
- uncertainty, sensitivity, and robustness
- validation and adequacy
- communication warnings
- model governance records
- SQL governance registries
- Haskell typed responsibility records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
