# Definite Integrals and Total Change

Companion code and reproducible workflows for **Definite Integrals and Total Change** in the **Calculus for Systems Modeling** series.

## Themes

- definite integrals as total change over an interval;
- signed accumulation and net change;
- area under the curve as accumulated quantity;
- Riemann sums and piecewise accumulation;
- interval bounds and orientation;
- units and dimensional meaning;
- net change versus total activity;
- numerical integration and trapezoidal approximation;
- sign-cancellation warnings;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A total-change estimate should state the integrand, bounds, integration variable, sign convention, units, numerical method, grid, and uncertainty.
