# Mathematical Deepening Notes

## Required distinctions

- directional derivative versus partial derivative
- unit direction versus arbitrary direction vector
- gradient versus full system explanation
- gradient norm versus feasible leverage
- steepest mathematical direction versus implementable direction
- local derivative versus finite scenario outcome
- Euclidean scaling versus normalized or weighted metrics
- contour tangency versus no global change

## Review checklist

- State the function.
- Define inputs and units.
- State the reference point.
- Report the gradient at that point.
- Define the direction vector.
- State the normalization rule.
- Compute the directional derivative.
- Compare local estimate with actual change when available.
- Check feasible-region constraints.
- Document local-validity risk.
