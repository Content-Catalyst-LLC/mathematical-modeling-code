# Directional Derivatives and Gradients

Companion code and reproducible workflows for **Directional Derivatives and Gradients** in the **Calculus for Systems Modeling** series.

## Themes

- directional derivatives
- gradients and gradient norms
- unit direction normalization
- dot products and local change
- steepest increase and decrease
- contour geometry
- feasible directions
- scaling and units
- reference states and local validity
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
