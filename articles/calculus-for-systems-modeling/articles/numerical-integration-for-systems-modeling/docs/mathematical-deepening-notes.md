# Mathematical Deepening Notes

Numerical integration connects Riemann sums, quadrature rules, interpolation, polynomial approximation, truncation error, convergence, conservation, cumulative sums, and gridded spatial fields.

## Review checklist

- Define the integrand, units, interval, and domain.
- Document integration rule and spacing.
- Use actual interval widths for irregular data.
- Preserve cumulative records, not only final totals.
- Document missing-value, smoothing, and interpolation choices.
- Run step-size or grid-refinement sensitivity checks.
- Compare against a benchmark or conservation identity where possible.
