# Numerical Integration for Systems Modeling

Companion code and reproducible workflows for **Numerical Integration for Systems Modeling** in the **Calculus for Systems Modeling** series.

## Themes

Riemann sums, trapezoidal approximation, Simpson-style approximation, cumulative integration, exposure burden, spatial integration, conservation checks, step-size sensitivity, integration error, model governance, and calculator scaffolding.

## Run

```bash
make smoke
make all
make calculators
make advanced
```
