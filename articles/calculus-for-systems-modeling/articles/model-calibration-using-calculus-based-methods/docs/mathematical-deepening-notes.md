# Mathematical Deepening Notes

Model calibration using calculus-based methods connects residual vectors, objective functions, gradients, Jacobians, Hessians, Gauss-Newton methods, nonlinear least squares, likelihood, regularization, constrained optimization, identifiability, uncertainty quantification, sensitivity analysis, and reproducible model governance.

## Required distinctions

- calibration versus validation
- fitted behavior versus predicted behavior
- residual reduction versus model truth
- parameter identifiability versus best-fit value
- local minimum versus global optimum
- loss-function choice versus neutral evidence
- uncertainty review versus single estimate

## Review checklist

- Preserve calibration data, preprocessing steps, exclusions, and measurement notes.
- Document parameter names, units, starting values, bounds, and estimates.
- Record loss function, weights, penalties, optimization method, and stopping rule.
- Export residual tables, candidate losses, convergence status, and warnings.
- Review identifiability, overfitting, sensitivity, uncertainty, and validation boundaries.
- Align claims with calibrated evidence and remaining uncertainty.
