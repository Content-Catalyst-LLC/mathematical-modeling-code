# Model Calibration Using Calculus-Based Methods

Companion code and reproducible workflows for **Model Calibration Using Calculus-Based Methods** in the **Calculus for Systems Modeling** series.

## Themes

- calibration data and residuals
- least-squares loss
- derivative-based optimization
- parameter bounds
- Jacobian and Hessian review
- identifiability and overfitting
- validation boundaries
- calibration governance
- reproducible calibration audits
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
