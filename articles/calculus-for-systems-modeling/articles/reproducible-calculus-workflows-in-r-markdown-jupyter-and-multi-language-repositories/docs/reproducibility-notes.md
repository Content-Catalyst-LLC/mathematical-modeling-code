# Reproducibility Notes

Reproducible calculus workflows connect mathematical specification, executable documentation, deterministic functions, numerical methods, dependency control, versioned artifacts, typed records, sensitivity diagnostics, validation checks, literate programming, scientific reporting, and model governance.

## Required distinctions

- reproducibility versus validity
- executable report versus clean-run evidence
- notebook output versus source-controlled artifacts
- generated output versus source data
- smoke tests versus mathematical proof
- metadata record versus interpretation judgment
- repository structure versus responsible use

## Review checklist

- Preserve equations, data status, parameters, units, commands, dependencies, outputs, diagnostics, warnings, and interpretation boundaries.
- Distinguish source data from generated evidence.
- Keep tables behind figures.
- Use clean-run commands and smoke tests.
- Export CSV, JSON, Markdown, and SQL-compatible records.
- Keep governance warnings attached to outputs and claims.
