# Reproducible Calculus Workflows in R Markdown, Jupyter, and Multi-Language Repositories

Companion code and reproducible workflows for **Reproducible Calculus Workflows in R Markdown, Jupyter, and Multi-Language Repositories** in the **Calculus for Systems Modeling** series.

## Themes

- reproducible calculus workflows
- R Markdown-style executable reporting
- Jupyter notebook placeholders
- multi-language repository design
- parameter records and assumption logs
- workflow artifact registers
- output metadata
- clean-run checks and smoke tests
- SQL governance registries
- Haskell typed workflow records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
