# Rules of Differentiation and Model Structure

Companion code and reproducible workflows for **Rules of Differentiation and Model Structure** in the **Calculus for Systems Modeling** series.

## Themes

- differentiation rules as model-structure tools;
- additive decomposition through the sum rule;
- interaction effects through the product rule;
- ratio and normalization behavior through the quotient rule;
- nested pathways through the chain rule;
- constraint interpretation through implicit differentiation;
- proportional growth and elasticity through logarithmic differentiation;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

Differentiation rules are not only symbolic procedures. They expose how a model is assembled and how local change moves through that structure.
