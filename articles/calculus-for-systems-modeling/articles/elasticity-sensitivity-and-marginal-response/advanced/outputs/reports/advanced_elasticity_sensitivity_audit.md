# Advanced Mathematical Audit: Elasticity, Sensitivity, and Marginal Response

## Formal topics included

- Marginal response
- Point elasticity
- Normalized parameter sensitivity
- Log-derivative identity
- Local versus global sensitivity
- Near-zero and sign-change warnings
- Finite-difference stability
- Parameter range review

## Modeling implication

A sensitivity result should state the baseline, operating point, units, perturbation size, parameter range, local/global scope, and domain restrictions.
