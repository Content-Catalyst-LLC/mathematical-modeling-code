Mathematical Deepening

Elasticity and sensitivity are derivative-based concepts whose meaning depends on baseline, scale, units, proportional interpretation, differentiability, domain restrictions, and local versus global scope.

Formal Sensitivity Conditions

Baseline

Derivative-based sensitivity is local to an operating point or parameter value.

Elasticity

Point elasticity requires meaningful proportional input and output change.

Normalized Sensitivity

Parameter sensitivity can be rescaled by baseline parameter and output values.

Finite Differences

Numerical sensitivity depends on perturbation size, smoothness, and noise behavior.
