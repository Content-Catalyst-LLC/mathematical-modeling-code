# Elasticity, Sensitivity, and Marginal Response

Companion code and reproducible workflows for **Elasticity, Sensitivity, and Marginal Response** in the **Calculus for Systems Modeling** series.

## Themes

- marginal response and local derivative interpretation;
- elasticity as relative responsiveness;
- normalized parameter sensitivity;
- local versus global sensitivity;
- scaling, units, and dimensionless interpretation;
- nonlinear response and operating points;
- threshold-sensitive marginal effects;
- numerical sensitivity and finite-difference checks;
- domain warnings near zero, sign changes, and boundaries;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A sensitivity claim should state the baseline, operating point, units, perturbation size, parameter range, domain restrictions, and whether the result is local, normalized, or global.
