# The Quotient Rule and Relative Change

Companion code and reproducible workflows for **The Quotient Rule and Relative Change** in the **Calculus for Systems Modeling** series.

## Themes

- quotient rule as ratio calculus;
- numerator and denominator effect decomposition;
- relative-rate identity;
- logarithmic derivatives;
- elasticity of ratios;
- per-capita and normalized indicators;
- near-zero denominator instability;
- typed ratio records;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A ratio derivative is never just one effect. It is a competition between numerator dynamics and denominator dynamics under domain, positivity, unit, and denominator-validity conditions.
