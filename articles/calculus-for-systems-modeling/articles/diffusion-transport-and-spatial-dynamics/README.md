# Diffusion, Transport, and Spatial Dynamics

Companion code and reproducible workflows for **Diffusion, Transport, and Spatial Dynamics** in the **Calculus for Systems Modeling** series.

## Themes

- state fields
- diffusion
- transport and advection
- advection-diffusion
- gradients and flux
- source and sink terms
- boundary conditions
- spatial domains
- conservation reasoning
- finite-difference grids
- stability ratios
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
