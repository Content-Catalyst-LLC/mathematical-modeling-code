# Mathematical Deepening Notes

## Required distinctions

- substitution as symbolic technique versus change-of-variables theorem;
- original variable versus transformed variable;
- transformed bounds versus original bounds;
- scale factor versus integrand;
- signed rate transformation versus nonnegative density transformation;
- monotonic versus nonmonotonic transformation;
- direct accumulation versus transformed accumulation;
- numerical convenience versus preserved modeling meaning.

## Pathology checklist

- missing scale factor;
- untransformed bounds;
- wrong sign convention;
- unit mismatch;
- nonmonotonic transformation treated as one-to-one;
- density transformed without absolute scale factor;
- normalized interval interpreted as original interval;
- residual between direct and transformed accumulation not audited.
