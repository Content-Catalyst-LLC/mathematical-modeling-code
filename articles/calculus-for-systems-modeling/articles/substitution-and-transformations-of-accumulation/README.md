# Substitution and Transformations of Accumulation

Companion code and reproducible workflows for **Substitution and Transformations of Accumulation** in the **Calculus for Systems Modeling** series.

## Themes

- substitution as transformed accumulation;
- change of variables;
- chain-rule structure;
- transformed bounds;
- differential scale factors;
- unit consistency;
- orientation and monotonicity;
- time rescaling and system clocks;
- density and rate transformations;
- original-versus-transformed integral residuals;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A transformed integral should preserve the same accumulated quantity by documenting the original variable, transformed variable, mapping, scale factor, bounds, units, orientation, and interpretation.
