# Case Study: Carbon Accumulation and Emissions Pathways

Advanced companion code and reproducible workflows for **Case Study: Carbon Accumulation and Emissions Pathways** in the **Calculus for Systems Modeling** series.

## Themes

- carbon stocks and flows
- emissions pathways as time-dependent functions
- cumulative emissions
- atmospheric burden
- fixed airborne fraction
- land and ocean sink assumptions
- impulse response and carbon persistence
- carbon budgets
- net zero and overshoot
- negative-emissions governance
- carbon-cycle feedback notes
- SQL governance registries
- Haskell typed pathway records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
