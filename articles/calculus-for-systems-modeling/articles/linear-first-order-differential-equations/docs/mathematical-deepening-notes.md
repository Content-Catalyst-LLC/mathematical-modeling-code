# Mathematical Deepening Notes

## Required distinctions

- first-order equation versus higher-order equation
- linear state dependence versus nonlinear state dependence
- homogeneous equation versus nonhomogeneous equation
- coefficient function versus forcing function
- integrating factor versus arbitrary multiplier
- equilibrium versus transient behavior
- analytical solution versus numerical approximation
- solver agreement versus model validity
- constant coefficient versus time-varying coefficient
- proportional loss assumption versus real process evidence

## Review checklist

- Define the state variable and units.
- Put the equation in standard form.
- Explain the coefficient \(p(t)\) and forcing term \(q(t)\).
- Document initial conditions, parameter values, and time horizon.
- State whether inputs are measured, estimated, hypothetical, or scenario-based.
- Compare analytical and numerical solutions when possible.
- Document limits of linear approximation.
