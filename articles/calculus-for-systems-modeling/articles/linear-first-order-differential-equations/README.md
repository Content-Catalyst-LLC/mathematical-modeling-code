# Linear First-Order Differential Equations

Companion code and reproducible workflows for **Linear First-Order Differential Equations** in the **Calculus for Systems Modeling** series.

## Themes

- standard linear first-order form
- homogeneous and nonhomogeneous equations
- integrating factors
- input-loss balance
- proportional adjustment
- equilibrium and transients
- time-varying coefficients
- analytical-versus-numerical comparison
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
