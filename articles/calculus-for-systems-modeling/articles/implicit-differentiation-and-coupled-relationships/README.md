# Implicit Differentiation and Coupled Relationships

Companion code and reproducible workflows for **Implicit Differentiation and Coupled Relationships** in the **Calculus for Systems Modeling** series.

## Themes

- implicit relationships as constraints;
- explicit versus implicit models;
- total differentials and tangent motion;
- implicit function theorem and regularity conditions;
- coupled systems and co-adjustment;
- equilibrium sensitivity;
- feedback and consistency relationships;
- Jacobian formulations;
- singularity and conditioning warnings;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

An implicit derivative is a local co-adjustment rate under a stated relationship. It is meaningful only with a documented constraint, branch, regularity condition, and domain of interpretation.
