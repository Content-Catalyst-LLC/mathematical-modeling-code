# Case Study: Modeling Population Dynamics

Companion code and reproducible workflows for **Case Study: Modeling Population Dynamics** in the **Calculus for Systems Modeling** series.

## Themes

- population state variables
- exponential growth
- logistic growth
- per-capita growth rates
- carrying capacity
- equilibrium and stability
- parameter interpretation
- calibration and data quality
- sensitivity and uncertainty
- SQL governance registries
- Haskell typed population records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
