# Case Study: Modeling Population Dynamics

Advanced companion code and reproducible workflows for **Case Study: Modeling Population Dynamics**.

Includes exponential growth, logistic growth, Allee thresholds, harvesting/removal, stochastic logistic simulation, two-patch migration, Leslie/stage-structured projection, spatial diffusion-style updates, calibration grid search, identifiability diagnostics, Catalyst Canvas governance, and reusable calculators.

## Run

```bash
make smoke
make all
make calculators
make advanced
```
