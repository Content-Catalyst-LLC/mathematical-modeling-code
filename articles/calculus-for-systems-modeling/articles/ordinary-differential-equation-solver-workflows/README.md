# Ordinary Differential Equation Solver Workflows

Companion code and reproducible workflows for **Ordinary Differential Equation Solver Workflows** in the **Calculus for Systems Modeling** series.

## Themes

- initial value problems
- state vectors and rate functions
- fixed-step RK4 benchmark workflows
- adaptive solver controls
- tolerances and error control
- stiffness warnings
- solver diagnostics
- step-size comparison
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
