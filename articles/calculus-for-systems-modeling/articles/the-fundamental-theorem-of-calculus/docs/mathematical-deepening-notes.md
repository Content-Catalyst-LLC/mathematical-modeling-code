# Mathematical Deepening Notes

## Required distinctions

- FTC Part I versus FTC Part II;
- derivative of an accumulation function versus endpoint evaluation;
- local rate versus accumulated change;
- net change versus total activity;
- state trajectory versus rate law;
- baseline state versus endpoint difference;
- analytic theorem versus numerical approximation;
- exact equality versus tolerance-based computational reconciliation.

## Pathology checklist

- rate and state defined on different intervals;
- unit mismatch;
- sign convention mismatch;
- missing flows;
- noisy cumulative data differentiated into unstable rates;
- coarse numerical integration grid;
- endpoint agreement misread as causal proof;
- net change misread as total activity.
