# Delay, Memory, and Time-Lagged Dynamics

Companion code and reproducible workflows for **Delay, Memory, and Time-Lagged Dynamics** in the **Calculus for Systems Modeling** series.

## Themes

- delayed feedback
- lagged response
- history functions
- delay differential equations
- memory kernels
- distributed delays
- overshoot and oscillation
- policy resistance
- delay sweeps
- numerical interpolation
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
