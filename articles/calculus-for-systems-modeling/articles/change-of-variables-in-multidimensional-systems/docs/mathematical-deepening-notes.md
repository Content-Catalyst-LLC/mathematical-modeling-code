# Mathematical Deepening Notes

## Required distinctions

- original variables versus transformed variables
- original region versus parameter region
- transformation map versus inverse map
- Jacobian matrix versus Jacobian determinant
- signed determinant versus absolute measure factor
- coordinate transformation versus harmless renaming
- density transformation versus density preservation
- invertible transformation versus many-to-one mapping
- singularity versus stable local transformation
- computational reparameterization versus physical interpretation

## Review checklist

- State original variables and transformed variables.
- Define the transformation map.
- Define original and transformed domains.
- Report the Jacobian matrix and determinant.
- Identify zero, near-zero, or negative determinant regions.
- Check whether the transformation is one-to-one on the domain.
- Include the correct area or volume element.
- Confirm total conservation when possible.
- Explain how transformed variables map back to the original system.
