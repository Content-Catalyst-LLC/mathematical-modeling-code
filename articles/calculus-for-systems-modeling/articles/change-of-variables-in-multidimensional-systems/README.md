# Change of Variables in Multidimensional Systems

Companion code and reproducible workflows for **Change of Variables in Multidimensional Systems** in the **Calculus for Systems Modeling** series.

## Themes

- multidimensional change of variables
- transformation maps
- mapped domains
- Jacobian determinants
- area and volume scaling
- polar, cylindrical, and spherical coordinates
- density conservation
- probability and state-space transformations
- singularity, invertibility, and orientation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
