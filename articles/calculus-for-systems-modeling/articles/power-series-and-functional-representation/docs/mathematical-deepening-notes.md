# Mathematical Deepening Notes

## Required distinctions

- power series versus finite polynomial approximation;
- center of expansion versus global domain;
- radius of convergence versus evaluation range;
- analytic equality versus formal Taylor construction;
- coefficient provenance versus fitted coefficient;
- truncation order versus full representation;
- remainder estimate versus visual fit;
- local validity versus global system claim;
- command-line calculator result versus article interpretation.

## Review checklist

- State the expansion center.
- State coefficient rule or provenance.
- State known convergence radius or interval.
- Check endpoint behavior where relevant.
- Report truncation order.
- Estimate or warn about remainder.
- Do not treat local polynomial behavior as global model truth.
