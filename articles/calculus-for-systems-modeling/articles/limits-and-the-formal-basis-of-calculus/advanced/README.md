# Advanced Layer: Limits and the Formal Basis of Calculus

This advanced layer supports mathematician-grade companion work for **Limits and the Formal Basis of Calculus**.

## Adds

- epsilon-delta and sequential-limit audit notes;
- forward difference;
- central difference;
- Richardson extrapolation;
- convergence-order estimation;
- roundoff and cancellation review;
- invariant interval checks;
- generated Markdown and JSON audit reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```
