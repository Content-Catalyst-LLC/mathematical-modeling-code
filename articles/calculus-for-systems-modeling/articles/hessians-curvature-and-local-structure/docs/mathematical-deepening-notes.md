# Mathematical Deepening Notes

## Required distinctions

- gradient versus Hessian
- first-order sensitivity versus second-order curvature
- diagonal second derivatives versus cross partials
- positive definite versus negative definite versus indefinite
- local convexity versus global convexity
- second-order approximation versus full nonlinear model
- unconstrained curvature versus feasible-direction curvature
- analytic, symbolic, automatic, and numerical Hessians
- scaling artifacts versus meaningful curvature

## Review checklist

- State the scalar function.
- Define inputs, units, and scaling.
- State the reference point.
- Report the gradient and Hessian.
- State derivative method.
- Classify curvature using determinant, eigenvalues, or quadratic form.
- Compare first-order and second-order approximations.
- Check cross partials and interaction interpretation.
- Document local-validity risk.
