# Hessians, Curvature, and Local Structure

Companion code and reproducible workflows for **Hessians, Curvature, and Local Structure** in the **Calculus for Systems Modeling** series.

## Themes

- Hessian matrices
- second partial derivatives
- local curvature and local shape
- cross partials and interaction structure
- second-order approximation
- convexity, concavity, and saddle points
- eigenvalue-style curvature classification
- conditioning and numerical stability
- critical points and optimization diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
