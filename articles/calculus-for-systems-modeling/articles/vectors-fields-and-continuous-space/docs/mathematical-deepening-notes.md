# Mathematical Deepening Notes

## Required distinctions

- scalar versus vector
- vector components versus coordinate-independent direction
- scalar field versus vector field
- continuous field versus gridded data
- field value versus field visualization
- magnitude versus direction
- smooth field assumption versus discontinuous system behavior
- continuous domain versus administrative or network boundary
- measured field versus simulated or interpolated field

## Review checklist

- State the domain.
- Define scalar-field and vector-field components.
- State units for coordinates, scalars, and vector components.
- Document coordinate conventions and projection assumptions.
- Report grid resolution or sampling density.
- State whether the field is measured, simulated, interpolated, or assumed.
- Identify missing data, boundaries, discontinuities, and smoothing assumptions.
- Avoid overinterpreting arrows, contours, heat maps, or streamlines.
