# Vectors, Fields, and Continuous Space

Companion code and reproducible workflows for **Vectors, Fields, and Continuous Space** in the **Calculus for Systems Modeling** series.

## Themes

- vectors and coordinate components
- vector magnitude and direction
- scalar fields
- vector fields
- continuous spatial domains
- field lines, contours, and visualization
- gridded approximation
- field assumptions and smoothness
- vector-field calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
