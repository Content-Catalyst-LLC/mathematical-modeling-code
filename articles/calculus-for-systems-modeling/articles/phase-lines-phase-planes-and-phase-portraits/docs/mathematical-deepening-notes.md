# Mathematical Deepening Notes

## Required distinctions

- phase line versus time-series plot
- phase plane versus two separate time-series plots
- vector field versus trajectory
- nullcline versus equilibrium
- local stability versus global behavior
- basin of attraction versus one selected initial condition
- separatrix versus ordinary trajectory
- visual pattern versus validated model behavior
- plotted range versus model domain
- numerical artifact versus system structure

## Review checklist

- Define state variables and meaningful state-space ranges.
- Document equations, parameters, and units.
- Identify equilibria and nullclines.
- Record vector-field grid resolution and scaling.
- Use multiple initial conditions for trajectories.
- Document solver method, step size, time horizon, and tolerance choices.
- Check whether simulated trajectories remain in meaningful regions.
- Explain whether the phase portrait is theoretical, exploratory, descriptive, scenario-based, or predictive.
