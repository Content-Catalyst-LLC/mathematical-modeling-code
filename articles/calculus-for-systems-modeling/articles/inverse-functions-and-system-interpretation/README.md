# Inverse Functions and System Interpretation

Companion code and reproducible workflows for **Inverse Functions and System Interpretation** in the **Calculus for Systems Modeling** series.

## Themes

- forward versus inverse thinking;
- one-to-one behavior and domain restrictions;
- inverse derivative formula;
- inverse function theorem;
- local versus global inverses;
- identifiability and recoverability;
- inverse problems and calibration;
- conditioning and stability;
- branch selection and interpretive ambiguity;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A recovered input, state, or parameter is meaningful only under a stated forward model, domain, branch, regularity condition, uncertainty structure, and conditioning review.
