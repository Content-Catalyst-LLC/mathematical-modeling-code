# Mathematical Deepening Notes

## Required distinctions

- forward model versus inverse interpretation;
- injectivity versus surjectivity onto the image;
- domain, codomain, and image;
- inverse function versus inverse relation;
- global inverse versus local inverse;
- derivative of inverse versus reciprocal of forward derivative;
- Jacobian inverse versus explicit matrix inversion;
- identifiability versus practical recoverability.

## Pathology checklist

- many-to-one forward map;
- domain not specified;
- branch not specified;
- forward derivative near zero;
- singular or ill-conditioned Jacobian;
- recovered input outside admissible domain;
- forward check does not reproduce target output;
- inverse result interpreted as causal proof.
