# Runge–Kutta Methods

Companion code and reproducible workflows for **Runge–Kutta Methods** in the **Calculus for Systems Modeling** series.

## Themes

- midpoint method
- second-order Runge–Kutta
- Heun-style slope averaging
- classical RK4
- stage diagnostics
- Euler-versus-RK4 comparison
- local and global error
- step-size sensitivity
- stability and stiffness warnings
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
