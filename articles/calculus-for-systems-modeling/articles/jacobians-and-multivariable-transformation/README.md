# Jacobians and Multivariable Transformation

Companion code and reproducible workflows for **Jacobians and Multivariable Transformation** in the **Calculus for Systems Modeling** series.

## Themes

- Jacobian matrices
- vector-valued functions
- local linear maps
- input-output sensitivity matrices
- coordinate transformations
- determinant scaling
- singularity and conditioning
- dynamic-system stability
- reference states and local validity
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
