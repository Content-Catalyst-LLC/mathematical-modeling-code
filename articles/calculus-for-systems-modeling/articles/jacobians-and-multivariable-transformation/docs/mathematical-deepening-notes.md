# Mathematical Deepening Notes

## Required distinctions

- Jacobian versus gradient
- scalar-valued versus vector-valued functions
- local linear map versus global nonlinear transformation
- determinant scaling versus full transformation behavior
- singularity versus ill conditioning
- analytic Jacobian versus numerical Jacobian
- matrix orientation conventions
- feasible perturbation versus arbitrary displacement
- local stability versus global dynamics

## Review checklist

- State the vector-valued function.
- Define inputs, outputs, units, and dimensions.
- State the reference point.
- State the Jacobian orientation convention.
- Report the matrix entries.
- Report determinant, rank, or conditioning where relevant.
- Compare Jacobian-predicted change with actual nonlinear change.
- Check perturbation feasibility.
- Document local-validity risk.
