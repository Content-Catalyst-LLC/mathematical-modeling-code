# Mathematical Deepening Notes

## Required distinctions

- state variable versus state field
- ODE trajectory versus PDE field evolution
- partial derivative versus total derivative
- domain geometry versus numerical grid
- initial condition versus boundary condition
- Dirichlet versus Neumann versus Robin boundary behavior
- diffusion versus transport
- transport versus wave propagation
- numerical instability versus modeled instability
- computed field versus observed data

## Review checklist

- Define the state field, units, and domain.
- Document initial conditions and boundary conditions.
- Record grid spacing, time step, and stability ratio.
- Explain the physical, ecological, social, or operational meaning of parameters.
- Save field summaries and stability checks alongside plots.
- Compare boundary choices when interpretation depends on them.
- Distinguish PDE model output from measured spatial data.
- Avoid interpreting unstable numerical output as system behavior.
