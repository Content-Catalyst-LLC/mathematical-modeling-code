# Introduction to Partial Differential Equations

Companion code and reproducible workflows for **Introduction to Partial Differential Equations** in the **Calculus for Systems Modeling** series.

## Themes

- state fields
- functions of several variables
- partial derivatives
- spatial domains
- boundary conditions
- initial conditions
- elliptic, parabolic, and hyperbolic PDEs
- diffusion
- transport
- wave behavior
- finite-difference grids
- stability ratios
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
