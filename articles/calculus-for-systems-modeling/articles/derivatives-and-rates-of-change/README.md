# Derivatives and Rates of Change

Companion code and reproducible workflows for **Derivatives and Rates of Change** in the **Calculus for Systems Modeling** series.

## Themes

- average versus instantaneous rates;
- derivative as a limit;
- derivative as a local linear map;
- units and dimensional interpretation;
- one-sided rates and boundaries;
- relative rates and elasticity;
- vector fields and state-space motion;
- finite-difference diagnostics;
- convergence-order and roundoff warnings;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A derivative is not just a slope. It is a local mathematical claim about change that requires domain, unit, smoothness, and numerical interpretation.
