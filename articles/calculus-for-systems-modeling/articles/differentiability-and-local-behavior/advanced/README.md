# Advanced Layer: Differentiability and Local Behavior

This advanced layer supports mathematician-grade companion work for **Differentiability and Local Behavior**.

## Adds

- derivative as local-linearization notes;
- one-sided derivative diagnostics;
- kink and nonsmooth behavior tests;
- Fréchet and Gâteaux differentiability notes;
- Jacobian/local-map interpretation;
- finite-difference stability checks;
- local linearization error review;
- invariant/boundary review;
- generated Markdown and JSON reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```
