# Finite Difference Methods

Companion code and reproducible workflows for **Finite Difference Methods** in the **Calculus for Systems Modeling** series.

## Themes

Discrete grids, time steps, forward/backward/central differences, second differences, stencils, explicit update rules, diffusion schemes, boundary conditions, stability, convergence, numerical artifacts, model governance, and calculator scaffolding.

## Run

```bash
make smoke
make all
make calculators
make advanced
```
