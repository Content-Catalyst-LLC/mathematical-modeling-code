# Mathematical Deepening Notes

Finite difference methods connect Taylor expansions, derivative approximation, stencil design, local truncation error, stability analysis, convergence, conservation, boundary treatment, and computational implementation.

## Review checklist

- Define equation family, domain, grid, and time step.
- Document the stencil and update rule.
- Record boundary conditions and edge handling.
- Compute stability ratios where applicable.
- Run grid and time-step sensitivity checks.
- Review numerical diffusion, oscillation, and instability.
- Preserve outputs and method metadata together.
