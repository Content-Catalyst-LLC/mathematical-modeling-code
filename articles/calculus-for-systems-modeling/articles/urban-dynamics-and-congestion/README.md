# Urban Dynamics and Congestion

Advanced companion code and reproducible workflows for **Urban Dynamics and Congestion** in the **Calculus for Systems Modeling** series.

## Themes

- urban stocks and flows
- traffic density, speed, and flow
- fundamental diagram of traffic flow
- bottlenecks, queues, delay, and capacity
- BPR travel-time functions
- generalized travel cost
- route choice, feedback, and network equilibrium
- induced demand and long-run adjustment
- public transit, multimodal systems, and accessibility
- land-use transport interaction
- freight, services, and curbside dynamics
- environmental, health, and distributional effects
- SQL governance registries
- Haskell typed urban mobility records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
