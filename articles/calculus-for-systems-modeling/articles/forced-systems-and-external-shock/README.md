# Forced Systems and External Shock

Companion code and reproducible workflows for **Forced Systems and External Shock** in the **Calculus for Systems Modeling** series.

## Themes

- endogenous versus exogenous dynamics
- forcing functions
- impulse shocks
- step forcing
- periodic forcing
- stochastic disturbance
- shock response
- recovery metrics
- cumulative deviation
- resilience and vulnerability
- scenario governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
