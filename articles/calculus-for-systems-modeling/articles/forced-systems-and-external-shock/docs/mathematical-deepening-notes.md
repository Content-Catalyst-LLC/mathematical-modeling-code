# Mathematical Deepening Notes

## Required distinctions

- endogenous dynamics versus exogenous forcing
- forcing function versus state variable
- impulse shock versus step change
- temporary disturbance versus durable regime shift
- periodic forcing versus irregular disturbance
- stochastic forcing versus deterministic scenario input
- baseline trajectory versus forced trajectory
- shock magnitude versus system vulnerability
- recovery metric versus resilience claim
- stress test versus forecast

## Review checklist

- Define model boundary and explain why the driver is treated as external.
- Document forcing function, shock type, timing, magnitude, duration, and units.
- Record baseline trajectory and forced trajectory.
- Define response metrics such as peak deviation, recovery time, cumulative deviation, overshoot, or threshold crossing.
- Test multiple shock timings and magnitudes.
- Record solver method, time step, discontinuity handling, and stochastic seed when relevant.
- Avoid presenting stress tests as forecasts unless evidence supports that interpretation.
