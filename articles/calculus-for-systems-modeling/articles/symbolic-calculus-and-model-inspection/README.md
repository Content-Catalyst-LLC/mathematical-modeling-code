# Symbolic Calculus and Model Inspection

Companion code and reproducible workflows for **Symbolic Calculus and Model Inspection** in the **Calculus for Systems Modeling** series.

## Themes

- symbolic differentiation
- symbolic integration records
- limit and boundary inspection
- equilibrium analysis
- Jacobian and Hessian workflows
- expression governance
- domain assumptions and excluded values
- exact-to-numeric workflow design
- model review and responsibility
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
