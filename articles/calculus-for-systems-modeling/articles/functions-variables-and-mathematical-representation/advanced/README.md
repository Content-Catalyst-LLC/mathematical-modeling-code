# Advanced Layer: Functions, Variables, and Mathematical Representation

This advanced layer upgrades the companion workflow for **Functions, Variables, and Mathematical Representation** so it is more credible for mathematicians, applied mathematicians, numerical analysts, and mathematically mature systems modelers.

## Focus

formal function structure, variables, parameters, codomain, image, and model representation

## What this layer adds

- formal definitions and modeling distinctions;
- proposition/counterexample/boundary-case HTML template;
- forward and central difference comparison;
- Richardson extrapolation;
- convergence-order estimation;
- roundoff-window review;
- invariant/domain-preservation checks;
- generated Markdown and JSON audit reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```

```text
outputs/reports/advanced_math_audit.md
outputs/json/advanced_math_audit.json
outputs/tables/convergence_study.csv
```
