Mathematical Deepening

This section strengthens Functions, Variables, and Mathematical Representation for mathematically advanced readers. It clarifies formal structure, assumptions, counterexamples, boundary behavior, and numerical interpretation.

Formal Mathematical Structure

Definition

A mathematical model should specify its domain, codomain, rule, assumptions, and intended interpretation. A computable expression alone is not a complete modeling object.

Proposition

Any derivative, integral, optimization result, or simulation trajectory should be interpreted only on the domain, feasible region, or state space where the model assumptions hold.

Counterexample

A function may return a numerical value outside the model’s intended domain. That value can be algebraically produced while remaining meaningless as a model output.

Boundary Case

Special care is required at zero, capacity limits, discontinuities, thresholds, singularities, and regime boundaries. These are common locations for modeling failure.

Numerical Analysis Notes

Forward Difference

The forward difference is usually first-order accurate for smooth functions, but it can be sensitive to step size and roundoff error.

Central Difference

The central difference is typically second-order accurate for smooth functions, making it a stronger default for local derivative estimation when symmetric evaluation is valid.

Richardson Extrapolation

Richardson extrapolation can improve estimates when the leading error term is known or behaves regularly under refinement.

Roundoff Warning

Smaller step sizes can eventually increase numerical error because subtraction cancellation and finite precision can dominate truncation error.
