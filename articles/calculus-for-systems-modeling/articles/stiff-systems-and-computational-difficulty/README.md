# Stiff Systems and Computational Difficulty

Companion code and reproducible workflows for **Stiff Systems and Computational Difficulty** in the **Calculus for Systems Modeling** series.

## Themes

- stiff systems
- time-scale separation
- explicit step-size limits
- implicit methods
- stability regions
- amplification-factor checks
- solver diagnostics
- scaling and nondimensionalization
- computational difficulty records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
