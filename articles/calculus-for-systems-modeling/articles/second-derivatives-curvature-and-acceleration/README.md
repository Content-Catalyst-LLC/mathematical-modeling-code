# Second Derivatives, Curvature, and Acceleration

Companion code and reproducible workflows for **Second Derivatives, Curvature, and Acceleration** in the **Calculus for Systems Modeling** series.

## Themes

- second derivatives as change in rate;
- acceleration and dynamic motion;
- concavity and local shape;
- curvature and bending;
- inflection candidates and sign-change review;
- second-order approximation;
- marginal change of marginal change;
- stability and optimization interpretation;
- numerical second derivatives;
- noisy curvature warnings;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A second-derivative claim is meaningful only when smoothness, operating point, first derivative, curvature interpretation, finite-difference method, and noise sensitivity are documented.
