# Advanced Layer: Continuity, Discontinuity, and Structural Breaks

This advanced layer supports mathematician-grade companion work for **Continuity, Discontinuity, and Structural Breaks**.

## Adds

- formal continuity and topological continuity notes;
- discontinuity-type examples;
- structural-break diagnostics;
- finite-difference slope analysis;
- level-jump and slope-break classification;
- one-sided boundary checks;
- invariant interval checks;
- piecewise model audit outputs;
- generated Markdown and JSON reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```
