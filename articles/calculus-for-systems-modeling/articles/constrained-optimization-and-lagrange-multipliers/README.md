# Constrained Optimization and Lagrange Multipliers

Companion code and reproducible workflows for **Constrained Optimization and Lagrange Multipliers** in the **Calculus for Systems Modeling** series.

## Themes

- constrained optimization
- equality constraints
- inequality constraints
- feasible regions and feasible directions
- Lagrange multipliers
- shadow values
- active and inactive constraints
- stationarity residuals
- second-order feasible-direction checks
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
