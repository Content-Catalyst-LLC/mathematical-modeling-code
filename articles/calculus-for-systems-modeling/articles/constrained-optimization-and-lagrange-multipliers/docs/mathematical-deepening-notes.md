# Mathematical Deepening Notes

## Required distinctions

- unconstrained versus constrained optimum
- objective function versus constraint function
- feasible region versus full input space
- equality constraint versus inequality constraint
- active constraint versus inactive constraint
- stationarity versus feasibility
- multiplier value versus real-world value
- local shadow value versus global policy conclusion
- unconstrained Hessian versus feasible-direction second-order condition
- scaling artifact versus meaningful constraint pressure

## Review checklist

- State the objective.
- Define each constraint.
- State variables, units, and scaling.
- Report candidate solution and objective value.
- Report constraint residuals.
- Report stationarity residuals.
- Report multiplier values and interpretation limits.
- Identify active, inactive, and violated constraints.
- Document local-validity risk.
