# The Divergence Theorem and Conservation Across Boundaries

Companion code and reproducible workflows for **The Divergence Theorem and Conservation Across Boundaries** in the **Calculus for Systems Modeling** series.

## Themes

- closed surfaces
- enclosed volumes
- outward normals
- boundary flux
- interior divergence
- source-sink behavior
- conservation across boundaries
- control volumes
- mesh and grid diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
