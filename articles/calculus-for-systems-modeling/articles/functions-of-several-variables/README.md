# Functions of Several Variables

Companion code and reproducible workflows for **Functions of Several Variables** in the **Calculus for Systems Modeling** series.

## Themes

- scalar-valued multivariable functions
- input spaces, domains, and ranges
- surfaces and contour diagnostics
- level curves and feasible regions
- interaction terms
- local neighborhoods and reference states
- constraint-aware evaluation
- variable definitions, units, and bounds
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
