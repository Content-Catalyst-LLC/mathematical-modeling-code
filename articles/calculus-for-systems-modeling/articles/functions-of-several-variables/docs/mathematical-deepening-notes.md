# Mathematical Deepening Notes

## Required distinctions

- mathematical domain versus modeling domain
- scalar-valued versus vector-valued functions
- input variables versus parameters
- feasible region versus rectangular input grid
- level curve versus surface plot
- additive structure versus interaction structure
- local neighborhood versus global domain
- computable output versus meaningful output

## Review checklist

- Define each input.
- State units and bounds.
- State mathematical and modeling domains.
- Identify feasible-region constraints.
- Document interaction terms.
- Mark local validity regions and extrapolation warnings.
