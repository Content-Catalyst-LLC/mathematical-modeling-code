# Condition and Scope Notes

Initial conditions, boundary conditions, and model scope connect differential equations, initial value problems, boundary value problems, partial differential equations, well-posedness, domain restriction, numerical stability, sensitivity analysis, parameter envelopes, and model governance.

## Required distinctions

- initial state versus model equation
- boundary condition versus spatial domain
- temporal scope versus forecast claim
- parameter range versus calibrated value
- model scope versus decision scope
- problem specification versus interpretation
- computation versus responsible use

## Review checklist

- Document initial values, units, sources, and uncertainty.
- Document boundary type, boundary values, edge behavior, and excluded surroundings.
- Record temporal, spatial, parameter, data, population, and use domains.
- Export condition and scope records to CSV, JSON, and Markdown.
- Use sensitivity checks for starting values and boundary choices.
- Attach claim boundaries wherever scope could be overextended.
