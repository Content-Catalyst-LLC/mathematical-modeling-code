# Initial Conditions, Boundary Conditions, and Model Scope

Companion code and reproducible workflows for **Initial Conditions, Boundary Conditions, and Model Scope** in the **Calculus for Systems Modeling** series.

## Themes

- initial condition records
- boundary condition records
- temporal, spatial, and parameter scope
- differential equation problem specification
- boundary effects and edge behavior
- initial-condition sensitivity
- scope creep and model misuse
- SQL governance registries
- Haskell typed scope records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
