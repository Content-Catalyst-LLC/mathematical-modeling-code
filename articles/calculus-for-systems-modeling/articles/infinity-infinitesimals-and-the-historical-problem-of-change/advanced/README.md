# Advanced Layer: Infinity, Infinitesimals, and the Historical Problem of Change

This advanced layer upgrades the companion workflow for **Infinity, Infinitesimals, and the Historical Problem of Change** so it is more credible for mathematicians, applied mathematicians, numerical analysts, and mathematically mature systems modelers.

## Focus

difference quotients, infinitesimals, limits, convergence, numerical approximation, and historical rigor

## What this layer adds

- formal definitions and modeling distinctions;
- proposition/counterexample/boundary-case HTML template;
- forward and central difference comparison;
- Richardson extrapolation;
- convergence-order estimation;
- roundoff-window review;
- invariant/domain-preservation checks;
- generated Markdown and JSON audit reports;
- stronger tests beyond smoke checks.

## Run

```bash
make smoke
```
