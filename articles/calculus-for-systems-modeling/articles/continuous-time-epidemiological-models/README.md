# Continuous-Time Epidemiological Models

Advanced companion code and reproducible workflows for **Continuous-Time Epidemiological Models** in the **Calculus for Systems Modeling** series.

## Themes

- continuous-time compartment models
- SIR and SEIR systems
- force of infection, incidence, and prevalence
- exponential early growth and doubling time
- basic and effective reproduction numbers
- herd-immunity and susceptible thresholds
- vaccination, waning immunity, and reporting assumptions
- interventions, behavior, and time-varying transmission
- heterogeneity and contact structure warnings
- SQL governance registries
- Haskell typed epidemiological records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```

This repository layer is educational. It is not medical advice, public-health guidance, or operational outbreak forecasting.
