# Typed Model Records and Functional Workflows in Haskell

Companion code and reproducible workflows for **Typed Model Records and Functional Workflows in Haskell** in the **Calculus for Systems Modeling** series.

## Themes

- Haskell typed records
- algebraic data types
- pure functions
- typed parameter sets
- model state records
- solver status records
- diagnostic records
- validation and governance
- reproducible exports
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
