# Financial Dynamics and Continuous Compounding

Advanced companion code and reproducible workflows for **Financial Dynamics and Continuous Compounding** in the **Calculus for Systems Modeling** series.

## Themes

- simple interest, compound interest, and continuous compounding
- exponential accumulation and variable-rate paths
- present value, future value, discount factors, and NPV
- cash flows, annuities, and valuation
- debt dynamics, amortization, payments, and balances
- inflation adjustment, real rates, and purchasing power
- returns, volatility, geometric growth, and sequence risk
- leverage, liquidity, default risk, and fragility
- SQL governance registries
- Haskell typed financial records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
