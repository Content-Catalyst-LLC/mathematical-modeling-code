# Sensitivity, Robustness, and Parameter Dependence

Companion code and reproducible workflows for **Sensitivity, Robustness, and Parameter Dependence** in the **Calculus for Systems Modeling** series.

## Themes

- local sensitivity
- normalized sensitivity and elasticity
- finite-difference sensitivity
- parameter sweeps
- robustness classifications
- threshold and fragility warnings
- interaction effects
- SQL governance registries
- Haskell typed sensitivity records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
