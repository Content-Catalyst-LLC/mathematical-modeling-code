# Sensitivity, Robustness, and Parameter Dependence Notes

Sensitivity, robustness, and parameter dependence connect derivatives with respect to parameters, finite differences, elasticity, gradients, Jacobians, Hessians, perturbation analysis, uncertainty propagation, local and global sensitivity methods, response surfaces, structural robustness, and model governance.

## Required distinctions

- baseline output versus robustness claim
- local sensitivity versus global sensitivity
- raw sensitivity versus elasticity
- parameter sweep versus uncertainty distribution
- robustness over tested range versus universal robustness
- numerical sensitivity versus structural model fragility
- sensitivity evidence versus model validity

## Review checklist

- Preserve baseline parameter values, units, sources, tested ranges, and assumptions.
- Document output metrics before ranking sensitivity.
- Record finite-difference step sizes and solver settings.
- Export sensitivity scores and robustness classifications.
- Flag thresholds, reversals, solver instability, and untested ranges.
- Keep claim boundaries attached to robustness statements.
