# Mechanistic Explanation and the Limits of Formalism

Companion code and reproducible workflows for **Mechanistic Explanation and the Limits of Formalism** in the **Calculus for Systems Modeling** series.

## Themes

- mechanistic explanation
- limits of formalism
- formal representation review
- parameter interpretation
- causal-claim boundaries
- explanatory scope
- validation and evidence status
- black-box risk
- SQL governance registries
- Haskell typed mechanism records
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
