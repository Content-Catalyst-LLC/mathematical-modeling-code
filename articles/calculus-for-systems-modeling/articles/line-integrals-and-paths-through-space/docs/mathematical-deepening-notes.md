# Mathematical Deepening Notes

## Required distinctions

- scalar line integral versus vector line integral
- path length versus field-path alignment
- path direction versus path geometry
- open path versus closed path
- path-dependent versus path-independent integral
- line integral over physical space versus state space
- scalar exposure accumulation versus vector work
- continuous path versus sampled computational path
- field interpolation versus field definition
- route total versus regional total

## Review checklist

- State the path and its parameterization.
- State the direction of travel.
- Define the scalar or vector field.
- State units for path coordinates, field values, and accumulated quantity.
- Report the parameter interval and path domain.
- Document sampling resolution and interpolation.
- Distinguish scalar accumulation from vector dot-product accumulation.
- Explain whether the result means exposure, work, cost, resistance, circulation, stress, or another quantity.
