# Line Integrals and Paths Through Space

Companion code and reproducible workflows for **Line Integrals and Paths Through Space** in the **Calculus for Systems Modeling** series.

## Themes

- scalar line integrals
- vector line integrals
- path-based accumulation
- work and field-path interaction
- circulation and closed paths
- path dependence and conservative fields
- state-space line integrals
- path sampling and computational approximation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
