# Mathematical Deepening Notes

## Required distinctions

- differential equation versus static equation
- state variable versus parameter
- rate law versus trajectory
- ordinary differential equation versus partial differential equation
- initial condition versus boundary condition
- analytical solution versus numerical approximation
- equilibrium versus stability
- linear behavior versus nonlinear feedback
- mechanistic equation versus empirical fit
- solver output versus responsible interpretation

## Review checklist

- Define each state variable and unit.
- State the rate law and its modeling justification.
- Document parameter values and uncertainty.
- Record initial and boundary conditions.
- State time horizon and solver method.
- Test sensitivity to step size and parameters.
- Identify validity scope and interpretive limits.
