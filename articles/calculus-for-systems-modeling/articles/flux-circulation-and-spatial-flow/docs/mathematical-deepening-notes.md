# Mathematical Deepening Notes

## Required distinctions

- flux versus circulation
- normal component versus tangent component
- crossing through a boundary versus movement around a path
- surface orientation versus path orientation
- positive flux versus negative flux
- clockwise versus counterclockwise circulation
- local divergence/curl versus boundary integrals
- path sampling versus surface mesh resolution
- vector-field meaning versus vector-field visualization
- boundary accounting versus loop interpretation

## Review checklist

- Define the vector field and its units.
- State surface, curve, or boundary geometry.
- Document normal direction and path orientation.
- Explain what positive and negative signs mean.
- Report path sampling, mesh resolution, interpolation, and smoothing.
- Separate normal crossing from tangent alignment.
- Avoid treating flux and circulation as interchangeable.
