# Flux, Circulation, and Spatial Flow

Companion code and reproducible workflows for **Flux, Circulation, and Spatial Flow** in the **Calculus for Systems Modeling** series.

## Themes

- vector fields
- flux through oriented boundaries
- circulation around oriented paths
- normal and tangent components
- boundary crossing
- loop movement
- divergence and curl connections
- orientation and sign conventions
- path and mesh sampling
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
