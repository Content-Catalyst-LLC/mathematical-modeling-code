# Case Study: Predator-Prey Systems

Advanced companion code and reproducible workflows for **Case Study: Predator-Prey Systems** in the **Calculus for Systems Modeling** series.

## Themes

- Lotka-Volterra predator-prey dynamics
- coupled nonlinear differential equations
- interaction terms and encounter assumptions
- nullclines and phase-plane reasoning
- equilibrium and Jacobian records
- local stability checks
- logistic prey limits
- functional responses and saturation
- harvesting and management terms
- stochastic paths
- calibration and identifiability diagnostics
- SQL governance registries
- Haskell typed interaction records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
