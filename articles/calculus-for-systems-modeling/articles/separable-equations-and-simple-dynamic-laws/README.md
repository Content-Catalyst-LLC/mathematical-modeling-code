# Separable Equations and Simple Dynamic Laws

Companion code and reproducible workflows for **Separable Equations and Simple Dynamic Laws** in the **Calculus for Systems Modeling** series.

## Run

```bash
make smoke
make all
make calculators
make advanced
```

## Included layers

Python, R, Julia, SQL, Haskell, C, C++, Fortran, Rust, Go, notebooks, docs, data, outputs, schemas, Canvas, advanced audit logic, and calculator scripts.
