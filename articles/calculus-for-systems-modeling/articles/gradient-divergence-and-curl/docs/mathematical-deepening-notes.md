# Mathematical Deepening Notes

## Required distinctions

- scalar field versus vector field
- gradient versus divergence versus curl
- local derivative operator versus global field behavior
- analytic derivative versus finite-difference approximation
- field definition versus field interpretation
- units of field values versus units of derivatives
- grid resolution versus derivative accuracy
- smoothing versus signal loss
- boundary estimates versus interior estimates
- local source-sink behavior versus literal creation or destruction

## Review checklist

- Define the scalar field and vector field.
- State coordinate system and units.
- Document derivative method.
- Report grid spacing, smoothing, interpolation, and boundary handling.
- Distinguish gradient from divergence and curl.
- Explain what each operator means in the modeled system.
- Avoid treating local diagnostics as complete system explanations.
