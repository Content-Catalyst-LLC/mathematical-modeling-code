# Gradient, Divergence, and Curl

Companion code and reproducible workflows for **Gradient, Divergence, and Curl** in the **Calculus for Systems Modeling** series.

## Themes

- scalar fields
- vector fields
- gradient and steepest increase
- divergence and source-sink behavior
- curl and local rotation
- finite-difference approximation
- grid spacing and boundary handling
- coordinate systems and units
- field-operator governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
