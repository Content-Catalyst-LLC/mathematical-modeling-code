# Infrastructure Flow and Capacity Dynamics

Advanced companion code and reproducible workflows for **Infrastructure Flow and Capacity Dynamics** in the **Calculus for Systems Modeling** series.

## Themes

- infrastructure stocks and flows
- throughput and capacity
- utilization and congestion
- queues, delay, and waiting time
- bottlenecks and effective capacity
- buffers and backlogs
- network flow and routing
- peak load and demand variation
- maintenance and capacity decay
- resilience, redundancy, and cascading failure
- SQL governance registries
- Haskell typed infrastructure records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
