# Mathematical Deepening Notes

## Required distinctions

- symbolic derivative versus numerical derivative
- forward difference versus backward difference versus central difference
- step size versus sampling interval
- truncation error versus roundoff error
- noise amplification versus real acceleration
- first derivative versus second derivative
- time derivative versus spatial gradient
- derivative estimate versus observed truth
- local parameter sensitivity versus global robustness
- boundary derivative versus interior derivative

## Review checklist

- Document data source, units, and sampling interval.
- Record the difference formula and derivative order.
- Record step size and run sensitivity checks.
- Document boundary handling.
- State smoothing, filtering, interpolation, or missing-data treatment.
- Compare against a synthetic or analytic benchmark where possible.
- Avoid overinterpreting derivative spikes in noisy data.
- Distinguish exploratory diagnostics from decision-support derivatives.
