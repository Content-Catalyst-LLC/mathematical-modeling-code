# Numerical Differentiation for Systems Modeling

Companion code and reproducible workflows for **Numerical Differentiation for Systems Modeling** in the **Calculus for Systems Modeling** series.

## Themes

- finite differences
- forward, backward, and central differences
- first and second derivative estimates
- spatial gradients
- step-size sensitivity
- truncation error
- roundoff error
- noise amplification
- derivative audits
- parameter sensitivity
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
