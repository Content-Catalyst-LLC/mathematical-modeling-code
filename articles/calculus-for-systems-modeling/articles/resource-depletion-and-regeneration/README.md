# Resource Depletion and Regeneration

Advanced companion code and reproducible workflows for **Resource Depletion and Regeneration** in the **Calculus for Systems Modeling** series.

## Themes

- resource stocks and flows
- renewable and nonrenewable resources
- extraction, harvest, pumping, and drawdown
- logistic regeneration and carrying capacity
- threshold recovery and collapse risk
- maximum sustainable yield and precautionary harvest
- groundwater, forests, fisheries, soils, minerals, and energy materials
- efficiency, substitution, rebound, and demand
- common-pool governance and adaptive management
- SQL governance registries
- Haskell typed resource records
- Catalyst Canvas governance
- reusable calculators

## Run

```bash
make smoke
make all
make calculators
make advanced
```
