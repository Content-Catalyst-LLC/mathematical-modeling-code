# Green's Theorem and Planar Systems

Companion code and reproducible workflows for **Green's Theorem and Planar Systems** in the **Calculus for Systems Modeling** series.

## Themes

- planar vector fields
- closed boundary curves
- circulation form of Green's theorem
- flux form of Green's theorem
- planar curl
- planar divergence
- boundary-region matching
- orientation and sign conventions
- boundary and area approximation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
