# Second-Order Equations and Oscillatory Systems

Companion code and reproducible workflows for **Second-Order Equations and Oscillatory Systems** in the **Calculus for Systems Modeling** series.

## Themes

- second derivatives and acceleration
- homogeneous second-order equations
- characteristic roots
- undamped oscillation
- damping regimes
- forced oscillation
- resonance
- phase-space interpretation
- numerical approximation
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
