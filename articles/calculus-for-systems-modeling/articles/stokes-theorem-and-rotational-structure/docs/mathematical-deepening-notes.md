# Mathematical Deepening Notes

## Required distinctions

- Stokes' theorem versus Green's theorem
- boundary circulation versus surface curl flux
- curl vector versus curl-normal component
- oriented surface versus arbitrary surface
- boundary curve versus unrelated loop
- right-hand-rule orientation versus reversed sign
- surface mesh approximation versus boundary sampling
- local rotational structure versus global circulation
- physical rotation versus modeled rotational tendency
- theorem equality versus numerical audit

## Review checklist

- Define the vector field and its units.
- State the surface and boundary curve.
- Confirm that the boundary curve bounds the selected surface.
- Document normal direction and boundary orientation.
- Explain right-hand-rule orientation.
- Report boundary sampling, surface mesh resolution, and curl-computation method.
- Compare boundary circulation and surface curl flux under refinement when possible.
