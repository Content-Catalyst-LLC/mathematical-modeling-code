# Stokes' Theorem and Rotational Structure

Companion code and reproducible workflows for **Stokes' Theorem and Rotational Structure** in the **Calculus for Systems Modeling** series.

## Themes

- oriented surfaces
- boundary curves
- circulation around a boundary
- curl through a surface
- curl flux
- normal vectors
- right-hand-rule orientation
- surface-boundary matching
- rotational structure
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
