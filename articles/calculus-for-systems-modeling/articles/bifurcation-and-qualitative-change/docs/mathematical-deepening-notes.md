# Mathematical Deepening Notes

## Required distinctions

- parameter change versus state change
- quantitative change versus qualitative change
- equilibrium branch versus trajectory
- critical value versus high value
- saddle-node loss of equilibria versus stability exchange
- transcritical crossing versus pitchfork branching
- Hopf onset of oscillation versus transient oscillation
- mathematical threshold versus observed threshold
- hysteresis versus ordinary lag
- numerical sweep resolution versus exact bifurcation location

## Review checklist

- Define state variables and meaningful domains.
- Identify the bifurcation parameter and its interpretation.
- Document model equations, parameter ranges, units, and assumptions.
- Record equilibrium candidates and branch status.
- Record derivative, Jacobian, or eigenvalue criteria used for stability classification.
- Identify whether critical values are exact, estimated, scenario-based, or policy-defined.
- Run sensitivity and numerical-resolution checks.
- Avoid presenting model thresholds as direct facts about the world without evidence.
