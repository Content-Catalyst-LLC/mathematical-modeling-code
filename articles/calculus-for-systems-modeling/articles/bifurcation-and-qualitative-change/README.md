# Bifurcation and Qualitative Change

Companion code and reproducible workflows for **Bifurcation and Qualitative Change** in the **Calculus for Systems Modeling** series.

## Themes

- bifurcation parameters
- qualitative change
- equilibrium branches
- stability shifts
- saddle-node bifurcations
- transcritical bifurcations
- pitchfork bifurcations
- Hopf bifurcations
- critical thresholds
- hysteresis
- numerical parameter sweeps
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
