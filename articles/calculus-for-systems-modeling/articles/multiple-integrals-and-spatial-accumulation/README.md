# Multiple Integrals and Spatial Accumulation

Companion code and reproducible workflows for **Multiple Integrals and Spatial Accumulation** in the **Calculus for Systems Modeling** series.

## Themes

- double integrals and triple integrals
- spatial accumulation
- density fields
- regions and boundaries
- area and volume elements
- weighted aggregation
- gridded numerical integration
- region masks and resolution checks
- population-weighted exposure
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
