# Mathematical Deepening Notes

## Required distinctions

- exact value versus approximation;
- absolute error versus relative error;
- truncation error versus roundoff error;
- numerical error versus model-form error;
- local validity versus global claim;
- tolerance versus guarantee;
- error estimate versus error bound;
- computation result versus modeling interpretation.

## Review checklist

- State the approximation method.
- State what was omitted.
- State truncation order, step size, or tolerance.
- Report absolute and relative error when a reference is available.
- Identify the local validity region.
- Explain whether plausible error could change interpretation.
