# Parameter Sweeps and Sensitivity Analysis

Companion code and reproducible workflows for **Parameter Sweeps and Sensitivity Analysis** in the **Calculus for Systems Modeling** series.

## Themes

- one-at-a-time parameter sweeps
- grid sweeps and response surfaces
- local finite-difference sensitivity
- elasticity-style sensitivity
- global sensitivity concepts
- robustness review
- fragility diagnosis
- parameter governance
- reproducible sensitivity audit workflows
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
