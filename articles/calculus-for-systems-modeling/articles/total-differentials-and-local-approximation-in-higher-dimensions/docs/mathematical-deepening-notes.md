# Mathematical Deepening Notes

## Required distinctions

- total differential versus actual finite change
- first-order approximation versus nonlinear model
- displacement vector versus coordinate partial
- tangent plane versus full response surface
- gradient direction versus feasible system movement
- local approximation versus global forecast
- approximation error versus model-form error
- feasible movement versus arbitrary mathematical displacement

## Review checklist

- State the function.
- Define each input and unit.
- State the reference point.
- State the displacement vector.
- Report partial derivatives at the reference point.
- Compute the total differential estimate.
- Compare with actual change when possible.
- Check feasible-region constraints.
- Document local-validity risk.
