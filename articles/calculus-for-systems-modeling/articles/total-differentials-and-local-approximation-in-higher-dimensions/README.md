# Total Differentials and Local Approximation in Higher Dimensions

Companion code and reproducible workflows for **Total Differentials and Local Approximation in Higher Dimensions** in the **Calculus for Systems Modeling** series.

## Themes

- total differentials
- local linear approximation
- tangent planes
- gradient-dot-displacement notation
- perturbation analysis
- feasible movement
- approximation error
- uncertainty propagation
- reference states and local validity
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
