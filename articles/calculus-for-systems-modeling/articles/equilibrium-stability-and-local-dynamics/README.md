# Equilibrium, Stability, and Local Dynamics

Companion code and reproducible workflows for **Equilibrium, Stability, and Local Dynamics** in the **Calculus for Systems Modeling** series.

## Themes

- equilibrium points
- perturbations
- stable and unstable equilibria
- semistability and thresholds
- phase-line interpretation
- local linearization
- Jacobian matrices
- eigenvalue reasoning
- basins of attraction
- numerical simulation
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
