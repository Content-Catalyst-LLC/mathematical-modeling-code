# Mathematical Deepening Notes

## Required distinctions

- equilibrium existence versus equilibrium meaning
- stability versus desirability
- local stability versus global stability
- perturbation scale versus shock scale
- boundary equilibrium versus interior equilibrium
- semistability versus full stability
- derivative test versus phase-line test
- Jacobian linearization versus global nonlinear dynamics
- basin of attraction versus single trajectory
- numerical stability versus modeled stability

## Review checklist

- Define state variables and meaningful domains.
- Explain the rate law and equilibrium candidates.
- Confirm equilibrium residuals are near zero.
- Record derivative or Jacobian values used for local classification.
- State whether stability claims are local or global.
- Document parameter conditions and perturbation scale.
- Run initial-condition and step-size sensitivity checks.
- Distinguish stable from desirable and fragile from unstable.
