# Mathematical Deepening Notes

## Required distinctions

- Taylor series versus Taylor polynomial;
- Taylor series versus Maclaurin series;
- expansion center versus global domain;
- approximation order versus full representation;
- derivative provenance versus fitted coefficient;
- convergence versus useful approximation;
- local validity versus global system claim;
- remainder estimate versus visual fit;
- command-line calculator result versus article interpretation.

## Review checklist

- State the expansion center.
- State approximation order.
- State derivative or coefficient provenance.
- State the evaluation region.
- Estimate or discuss the remainder.
- Do not treat a local polynomial as global system truth.
