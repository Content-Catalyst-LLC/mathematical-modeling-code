# Mathematical Deepening Notes

## Required distinctions

- composite function versus direct function;
- derivative as local linear map;
- one-dimensional chain rule versus multivariable chain rule;
- Jacobian composition versus scalar derivative product;
- direct partial derivative versus indirect chain-rule pathway;
- feedback-mediated derivative terms;
- automatic differentiation of code versus derivative of the modeled system;
- local derivative versus global pathway claim.

## Pathology checklist

- domain mismatch between inner and outer functions;
- continuous but nondifferentiable links;
- thresholds, max functions, clipping, and conditionals;
- finite-difference checks near discontinuities;
- composite derivatives interpreted as causal proof;
- automatic differentiation applied to implementation artifacts.
