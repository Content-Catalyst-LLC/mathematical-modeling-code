# The Chain Rule and Composite Change in Interacting Systems

Companion code and reproducible workflows for **The Chain Rule and Composite Change in Interacting Systems** in the **Calculus for Systems Modeling** series.

## Themes

- chain rule as mediated change;
- composite functions and nested pathways;
- climate-response pathway examples;
- policy-behavior-contact-outcome pathways;
- feedback-mediated effects;
- multivariable chain rule and Jacobian composition;
- automatic differentiation and computational graphs;
- finite-difference checks;
- generated Markdown/JSON audit reports.

## Run

```bash
make smoke
make advanced
make all
```

## Principle

A composite derivative should be interpreted as a pathway of local sensitivities, not as an anonymous black-box response.
