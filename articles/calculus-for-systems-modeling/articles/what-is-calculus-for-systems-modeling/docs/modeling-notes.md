# Modeling Notes

Calculus for systems modeling connects local change, cumulative consequence, feedback, approximation, and dynamic behavior.

## Core interpretation

- Derivatives represent rates, local sensitivity, and marginal response.
- Integrals represent accumulation, exposure, burden, and flow-to-stock reasoning.
- Differential equations represent evolving states.
- Gradients and partial derivatives represent multivariable sensitivity.
- Numerical methods turn formal relationships into inspectable workflows.

## Responsible use

A calculus-based model should document assumptions, units, parameters, boundary conditions, numerical methods, limitations, and uncertainty.
