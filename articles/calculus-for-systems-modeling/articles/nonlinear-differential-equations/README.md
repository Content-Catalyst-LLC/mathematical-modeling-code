# Nonlinear Differential Equations

Companion code and reproducible workflows for **Nonlinear Differential Equations** in the **Calculus for Systems Modeling** series.

## Themes

- nonlinear rate laws
- powers and products
- interaction terms
- logistic growth
- bounded growth and saturation
- thresholds and regime change
- equilibria and stability
- local linearization
- phase behavior
- numerical simulation
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
