# Calculus for Systems Modeling: Notes

Calculus provides the formal language for representing continuous change, accumulation, marginal response, optimization, spatial flow, and dynamic behavior.

## Modeling Cautions

- Smooth models can hide discontinuities.
- Derivatives can be difficult to estimate from noisy data.
- Integrals depend on the quality of the underlying rate function.
- Numerical methods introduce approximation error.
- Parameter choices can strongly shape trajectories.
- Calculus supports judgment; it does not replace it.
