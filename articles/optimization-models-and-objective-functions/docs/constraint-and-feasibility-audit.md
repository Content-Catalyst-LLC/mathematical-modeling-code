# Constraint and Feasibility Audit

## Review questions

- Which constraints are hard?
- Which constraints are soft or negotiable?
- Which limits are physical, legal, ethical, operational, financial, or assumed?
- Does the model have missing constraints?
- Does the model become infeasible under realistic scenarios?
- Are integer or binary choices represented where implementation requires them?
- Are feasibility tolerances acceptable in real units?

## Principle

A solution is not useful merely because it is mathematically feasible. It should also be implementable, auditable, and aligned with the decision context.
