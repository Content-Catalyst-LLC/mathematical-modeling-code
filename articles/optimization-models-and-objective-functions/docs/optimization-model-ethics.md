# Ethics of Optimization Modeling

Optimization models can shape decisions about resources, access, labor, safety, finance, environment, infrastructure, and public services.

## Risks

- cost-only objectives hide harm;
- aggregate benefit hides unequal distribution;
- missing constraints make harmful actions appear optimal;
- hidden weights encode value judgments;
- fairness is reviewed only after optimization;
- solver output is treated as authority;
- uncertainty is ignored when conditions are unstable.

## Responsible practice

- document objective functions;
- explain constraints and omissions;
- preserve feasible alternatives;
- test sensitivity;
- report subgroup impacts;
- distinguish model recommendation from institutional decision;
- keep data, solver settings, and outputs auditable.
