# Workflow Ethics and Governance

Scientific computing workflows can make outputs appear objective and final, even when they depend on hidden assumptions, fragile dependencies, untracked data transformations, or weak validation.

## Responsible practice

- separate code, data, configuration, and outputs;
- record dependencies and runtime context;
- preserve run manifests, logs, and output hashes;
- write tests and validation diagnostics;
- document limitations and intended use;
- keep human review visible.

## Principle

Workflow discipline is an ethical practice when model outputs influence real decisions.
