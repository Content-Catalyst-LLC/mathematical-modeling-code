# Data Pipeline and Provenance Guide

## Data review questions

- Where did the data come from?
- What schema is expected?
- What units are used?
- How are missing values handled?
- What transformations produce model-ready inputs?
- What aggregation choices are made?
- Can processed data be regenerated from documented inputs?

## Principle

Data transformation is part of the model. It should be documented, tested, and preserved.
