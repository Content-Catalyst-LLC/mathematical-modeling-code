# Calibration Ethics and Governance

Fitted models can appear more objective than they are.

## Ethical risks

- data selection changes fitted values;
- objective functions privilege some errors;
- parameter constraints shape results invisibly;
- overfitting creates false confidence;
- uncertainty is hidden behind best-fit values;
- fitted models are used beyond their evidence base.

## Responsible practice

- preserve calibration data and inclusion rules;
- document objective functions and weights;
- export residual diagnostics;
- report parameter uncertainty;
- validate beyond calibration data;
- state use limits clearly.
