# Identifiability and Parameter Meaning

A parameter is identifiable when evidence can distinguish its value.

## Risks

- many parameter combinations fit equally well;
- parameters compensate for missing model structure;
- effective parameters are overinterpreted as physical quantities;
- fitted values depend strongly on starting values or bounds;
- parameter uncertainty is hidden.

## Responsible practice

- inspect candidate scores and objective surfaces;
- use sensitivity and uncertainty analysis;
- report parameter bounds and constraints;
- separate explanatory parameters from tuning parameters;
- avoid overclaiming weakly identified values.
