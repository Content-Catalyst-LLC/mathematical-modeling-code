# Model Form Error Types

Model form error is systematic mismatch between model structure and system behavior.

## Common types

- missing mechanism;
- omitted variable;
- wrong functional form;
- boundary error;
- aggregation error;
- scale mismatch;
- regime error;
- invalid transfer;
- hidden feedback or delay;
- causal overreach.

## Principle

Parameter tuning cannot repair an inappropriate model structure. Structural uncertainty requires model-form review, comparison, and transparent communication.
