# Structural Uncertainty Ethics

Model form error has ethical stakes because model structure can shape institutional judgment.

## Ethical risks

- single-model authority;
- hidden omitted mechanisms;
- aggregation that hides harm;
- suppressed model disagreement;
- validation overclaim;
- decision overreach;
- absent use-limit statements.

## Responsible practice

- document structural assumptions;
- compare plausible forms when feasible;
- preserve disagreement across models;
- communicate validation domain;
- state use limits;
- connect structural uncertainty to decisions and affected stakeholders.
