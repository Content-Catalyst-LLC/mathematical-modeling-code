# Unit Register Specification

## Article

**Dimensional Analysis, Units, and Scale**

## Central claim

Units and dimensions are part of model meaning. They are not decorative labels.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| quantity_type | stock, flow, rate, ratio, index, count, cost, probability, etc. |
| unit | Declared unit |
| dimension | Dimension or constructed measurement type |
| expected_range | Valid or plausible range |
| review_question | Unit and scale review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include flows, rates, probabilities, bounded values, normalized scores, converted quantities, and any parameter whose unit depends on time step or spatial scale.
