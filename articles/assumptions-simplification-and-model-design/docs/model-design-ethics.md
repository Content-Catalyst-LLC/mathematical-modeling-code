# Model Design Ethics

Model design is not neutral. Assumptions and simplifications determine what becomes visible and what disappears.

## Ethical review questions

- Are affected groups aggregated away?
- Are proxy variables being treated as the target concept?
- Does the model omit harms, externalities, or distributional effects?
- Does the objective function hide value judgments?
- Does the model communicate uncertainty honestly?
- Can users challenge the assumptions?
- Is model output being treated as a decision rather than evidence?

## Responsible practice

- state boundaries;
- identify simplifications;
- document assumptions;
- report uncertainty;
- preserve review trails;
- separate model output from institutional accountability.
