# Validation and Sensitivity Plan

## Validation question

Is the model adequate for its intended purpose under its stated assumptions?

## Sensitivity questions

- Which assumptions matter most?
- Which parameters drive outputs?
- Which omitted details could change conclusions?
- Which scenarios produce failure?
- Which assumptions require empirical validation?

## Required before operational use

- empirical observations;
- calibration and validation split;
- residual diagnostics;
- parameter uncertainty intervals;
- structural model comparison;
- domain review;
- documented adequacy statement;
- prohibited-use statement.
