# Numerical Verification and Validation Guide

## Verification

Verification checks whether code implements the intended numerical method.

Examples:
- unit tests for derivative functions;
- known-case comparisons;
- convergence tests;
- residual checks;
- step-size comparisons;
- state constraint tests.

## Validation

Validation checks whether the underlying mathematical model is credible for the intended real-world purpose.

## Principle

A model can be numerically accurate and substantively wrong. Numerical verification does not replace model validation.
