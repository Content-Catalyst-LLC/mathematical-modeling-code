# Ethics of Numerical Modeling

Numerical methods influence decisions in engineering, health, public policy, infrastructure, AI, climate risk, finance, and sustainability.

## Risks

- solver output appears more exact than it is;
- tolerances and step sizes are hidden from decision-makers;
- coarse discretization hides local harms;
- numerical precision implies false certainty;
- computational outputs cannot be reproduced;
- method choice is treated as neutral;
- unstable approximations become policy evidence.

## Responsible practice

- document solver choices and numerical settings;
- run convergence and stability diagnostics;
- report meaningful precision only;
- preserve code, inputs, outputs, and run logs;
- communicate uncertainty and approximation limits;
- state intended use and use limits clearly.
