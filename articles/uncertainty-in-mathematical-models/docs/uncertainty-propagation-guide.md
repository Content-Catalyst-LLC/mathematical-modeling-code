# Uncertainty Propagation Guide

Uncertainty propagation asks how uncertainty in inputs, parameters, assumptions, or model structure affects uncertainty in outputs.

## Steps

1. Name uncertainty sources.
2. Document plausible ranges or distributions.
3. Preserve baseline values.
4. Run propagation or sampling workflow.
5. Summarize output distribution.
6. Report threshold probability.
7. Document what uncertainty is excluded.
8. Connect uncertainty to interpretation and decision support.

## Principle

A precise-looking model output is not responsible unless the uncertainty behind it has been examined.
