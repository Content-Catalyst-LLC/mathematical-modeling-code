# ABM Model Register Specification

## Article

**Agent-Based Models and Emergent Behavior**

## Central claim

An agent-based model is a computational mathematical model whose system-level outputs arise from agent states, local rules, interactions, environments, scheduling, and stochastic variation.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| component_type | agent_state, behavior_rule, interaction_structure, environment, schedule, simulation_protocol, validation_diagnostic |
| rule_or_structure | Formal or computational rule |
| interpretation | Plain-language meaning |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include behavior rules, threshold parameters, interaction topology, initialization, scheduling, stochastic replication, validation diagnostics, and outputs used for decision support.
