# Emergence Review Guide

## Review questions

- What macro-level pattern emerged?
- Which micro-level rules generated it?
- Which parameters are most important?
- Does the pattern survive alternative seeds and initial conditions?
- Does the pattern survive alternative interaction structures?
- Is the pattern validated against empirical or theoretical evidence?
- Is emergence being used as explanation or as a vague label?

## Principle

Emergent behavior is not evidence by itself. It is a model output that requires mechanism, validation, sensitivity analysis, and interpretation.
