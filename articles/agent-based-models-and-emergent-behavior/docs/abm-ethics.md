# Ethics of Agent-Based Modeling

Agent-based models can influence public health, transportation, urban policy, platforms, welfare, ecology, emergency planning, and organizational strategy.

## Risks

- agent categories oversimplify or stereotype groups;
- behavior rules encode biased assumptions;
- historical calibration data carries inequity;
- single-run simulations are treated as prediction;
- emergent outcomes are framed as inevitable;
- interventions impose unequal burdens;
- exploratory models are used beyond validation scope.

## Responsible practice

- document agents, rules, interactions, and schedules;
- preserve random seeds and simulation settings;
- run ensembles;
- report uncertainty and distributional outcomes;
- validate multiple patterns;
- state use limits clearly;
- treat model outputs as decision support, not automatic authority.
