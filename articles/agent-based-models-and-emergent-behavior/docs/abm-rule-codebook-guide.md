# ABM Rule Codebook Guide

## Core checks

- What does each agent represent?
- What states can each agent occupy?
- Which rules update agent state?
- Are rules deterministic, probabilistic, adaptive, or scenario-based?
- What evidence supports each rule?
- Who interacts with whom?
- Does scheduling affect outcomes?
- Are enough replications run to characterize stochastic variation?

## Principle

Emergence should be traceable. A model should explain how agent rules, interaction structure, and boundary conditions generate macro-level outcomes.
