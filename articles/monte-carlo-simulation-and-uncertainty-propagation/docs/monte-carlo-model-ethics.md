# Ethics of Monte Carlo Modeling

Monte Carlo simulation can support decisions in public policy, infrastructure, climate adaptation, finance, health, safety engineering, environmental regulation, logistics, and artificial intelligence.

## Risks

- arbitrary distributions appear objective;
- independence assumptions hide compound risk;
- threshold choices manipulate perceived risk;
- rare outcomes are ignored or exaggerated;
- output probabilities are treated as direct facts;
- false precision masks deep uncertainty;
- code, seeds, and input assumptions are not auditable.

## Responsible practice

- document input distributions and evidence;
- review correlation and dependence assumptions;
- report quantiles, threshold probabilities, and tails;
- run convergence and seed diagnostics;
- preserve code, seeds, inputs, outputs, and logs;
- state intended use and use limits clearly.
