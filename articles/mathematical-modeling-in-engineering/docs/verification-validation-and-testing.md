# Verification, Validation, and Testing

Verification asks whether the model was implemented correctly.
Validation asks whether the model is adequate for intended engineering use.

## Evidence types

- code tests;
- benchmark cases;
- numerical convergence;
- laboratory tests;
- prototype tests;
- field data;
- inspection records;
- operational monitoring.

## Principle

Calibration and simulation are not substitutes for purpose-specific validation.
