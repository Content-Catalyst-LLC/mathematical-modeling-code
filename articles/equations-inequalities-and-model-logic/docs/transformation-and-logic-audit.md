# Transformation and Logic Audit

## Common transformations

- logarithms;
- ratios;
- standardization;
- normalization;
- squaring both sides;
- linearization;
- constraint relaxation;
- penalty conversion.

## Audit questions

- What conditions are required for the transformation?
- Does the transformation preserve interpretation?
- Does it introduce or remove feasible values?
- Does it change a hard constraint into a soft one?
- Does it create extraneous solutions?
- Is the transformation visible in the article and code?

## Conditional logic

If-then rules, threshold triggers, clipping, solver stopping criteria, and exception handling are part of the model and must be documented.
