# Inequality and Domain Guide

## Core inequality roles

- nonnegativity;
- upper and lower bounds;
- probability domains;
- budget constraints;
- safety thresholds;
- minimum service requirements;
- chance constraints;
- robust constraints.

## Domain checks

- probabilities remain in [0, 1];
- logarithms use positive inputs;
- divisions avoid zero denominators;
- counts remain integer-valued;
- bounded state variables remain feasible;
- observed data ranges are not overextended without warning.

## Review questions

- What is the source of the inequality?
- Is it physical, empirical, computational, legal, ethical, or policy-based?
- Is it hard or soft?
- Does the code enforce it the same way the documentation states it?
