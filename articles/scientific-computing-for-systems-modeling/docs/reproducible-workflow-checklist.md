# Reproducible Scientific Computing Checklist

## Inputs
- Source data documented
- Synthetic data clearly labeled
- Parameters stored in a structured file
- Units and assumptions recorded

## Code
- Functions named clearly
- Scripts separated by purpose
- Random seeds documented
- Dependencies listed
- Outputs written to predictable locations

## Computation
- Numerical method identified
- Step size or tolerance documented
- Sensitivity checks included
- Runtime or performance concerns noted

## Outputs
- Raw outputs stored
- Summary outputs exported
- Diagnostics generated
- Interpretation notes included

## Review
- Results reproducible from scratch
- Assumptions inspectable
- Limitations stated
