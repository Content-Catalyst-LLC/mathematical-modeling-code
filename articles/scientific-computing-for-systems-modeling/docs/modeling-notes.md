# Scientific Computing for Systems Modeling: Notes

Scientific computing translates mathematical models into executable workflows.

## Core Questions

- What mathematical model is being implemented?
- What numerical method is being used?
- What assumptions are embedded in the algorithm?
- What data structures represent the system?
- What parameters and scenarios are being tested?
- Are outputs reproducible and documented?
- Are numerical errors, stability, and convergence considered?

## Interpretation Cautions

- Code execution is not proof of model validity.
- Reproducible workflows can still reproduce flawed assumptions.
- Numerical outputs depend on algorithm choice and computational settings.
- Visualization can clarify or distort interpretation.
- Speed should not be optimized before correctness and transparency.
