# Model Pluralism and Scenario Thinking

Complex systems rarely justify a single-model worldview.

## Review questions

- Which model family clarifies feedback?
- Which model family clarifies networks and dependencies?
- Which model family clarifies heterogeneous behavior?
- Which scenarios represent plausible futures?
- Where do models agree and disagree?
- Which conclusions remain robust across model forms?

## Principle

Model disagreement can be useful evidence about fragile assumptions.
