# Boundaries, Scale, and System Context

Ecological model meaning depends on boundary and scale choices.

## Review questions

- What spatial boundary is being modeled?
- What time horizon matters?
- Which species, stocks, flows, habitats, or human pressures are included?
- Which effects are outside the model but inside ecological reality?
- What changes if the scale shifts?

## Principle

Boundary choices shape what counts as ecological harm, recovery, resilience, and sustainability.
