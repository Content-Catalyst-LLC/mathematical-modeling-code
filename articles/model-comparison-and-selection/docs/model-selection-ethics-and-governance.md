# Model Selection Ethics and Governance

Model selection shapes what evidence remains visible and what alternatives disappear from decision-making.

## Ethical risks

- cherry-picking a model that supports a preferred conclusion;
- metric shopping;
- complexity bias;
- hiding rejected alternatives;
- selecting a model for one purpose and using it for another;
- selecting an opaque model where public explanation is needed.

## Responsible practice

- document candidate models;
- state selection criteria;
- report multiple metrics;
- preserve rejected alternatives and their lessons;
- include uncertainty and robustness review;
- connect selection to intended use and use limits.
