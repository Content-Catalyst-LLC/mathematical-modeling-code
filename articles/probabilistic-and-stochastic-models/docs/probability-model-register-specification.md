# Probability Model Register Specification

## Article

**Probabilistic and Stochastic Models**

## Central claim

Probabilistic models represent uncertainty as part of model structure, not as an afterthought.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| model_component | random variable, distribution choice, parameter uncertainty, derived risk, conditional statement, simulation setting, validation diagnostic |
| distribution_or_rule | Distribution, probability statement, or risk rule |
| interpretation | Plain-language meaning |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include distribution choices, tail-risk measures, dependence assumptions, priors, conditional probability statements, simulation settings, and outputs used for decision support.
