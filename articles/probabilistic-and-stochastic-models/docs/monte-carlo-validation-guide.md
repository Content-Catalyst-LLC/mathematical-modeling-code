# Monte Carlo Validation Guide

## Review questions

- What uncertainty sources are sampled?
- Which distributions were used and why?
- Are sampled quantities independent or dependent?
- Is the random seed recorded?
- Is the simulation count adequate for tail estimates?
- Are invalid model states recorded?
- Are shortage probability and shortage severity separated?
- Are sensitivity checks run on distributional assumptions?

## Output requirements

- simulation run table;
- scenario-level risk summary;
- probability model register;
- tail-risk diagnostics;
- model audit card.
