# Recurrence Model Register Specification

## Article

**Discrete Models and Recurrence Relations**

## Central claim

A recurrence relation is a structured claim about stepwise change. It defines how the model moves from one state to the next.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| component_type | state variable, update rule, initial condition, boundary rule, parameter, output diagnostic, step definition |
| expression | Mathematical or computational expression |
| interpretation | Plain-language meaning |
| domain_or_step | Domain, time-step meaning, or valid range |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include update rules, boundary rules, threshold rules, step definitions, initial conditions, adaptive states, and outputs used for decision support.
