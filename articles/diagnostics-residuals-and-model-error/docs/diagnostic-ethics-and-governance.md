# Diagnostic Ethics and Governance

Model error has ethical stakes because error is not always evenly distributed or honestly communicated.

## Ethical risks

- reporting only one favorable metric;
- hiding subgroup or spatial error;
- removing outliers without investigation;
- ignoring threshold-specific error;
- using uncertainty bands to hide structural failure;
- failing to state where the model is weak.

## Responsible practice

- preserve residuals;
- report multiple metrics;
- review bias and subgroup performance;
- flag outliers and stress cases;
- connect diagnostics to decision thresholds;
- document use limits and structural-error concerns.
