# Threshold and Decision Error

Decision support changes the meaning of residuals.

A small residual can be consequential if it changes an action trigger. A large residual may be less important if it does not change the decision.

## Required questions

- Does the model overpredict or underpredict near the action threshold?
- How many cases disagree across observed and predicted threshold status?
- Are tail errors decision-relevant?
- Does error affect scenario ranking?
- Does uncertainty change the recommended action?

## Principle

Error should be interpreted relative to the model's purpose, not only its size.
