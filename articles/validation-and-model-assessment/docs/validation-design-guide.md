# Validation Design Guide

## Article

**Validation and Model Assessment**

## Central claim

Validation evaluates whether a mathematical model is credible enough for a specified purpose. It is conditional, evidence-based, and tied to model use.

## Required validation records

| Record | Purpose |
|---|---|
| conceptual_validity | Reviews structure, assumptions, boundaries, and purpose |
| implementation_verification | Confirms code implements the model specification |
| data_validation | Reviews evidence quality, units, provenance, and alignment |
| residual_diagnostics | Assesses post-fit error behavior |
| out_of_sample_assessment | Reviews generalization beyond calibration data |
| benchmark_comparison | Compares model with simpler or established alternatives |
| uncertainty_review | Examines sensitivity, robustness, and uncertainty |
| fitness_for_purpose | Judges adequacy for intended use |
