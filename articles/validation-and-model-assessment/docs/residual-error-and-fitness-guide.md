# Residual Error and Fitness-for-Purpose Guide

## Error diagnostics

- mean error;
- mean absolute error;
- root mean squared error;
- maximum absolute error;
- residual pattern over time;
- error by scenario;
- error near thresholds.

## Fitness-for-purpose questions

- What use is being validated?
- What error level is acceptable for that use?
- Could uncertainty change the decision?
- Does the model fail in consequential regions?
- Are use limits clearly documented?

## Principle

A model is not simply valid or invalid. It is credible enough, or not credible enough, for a specified purpose.
