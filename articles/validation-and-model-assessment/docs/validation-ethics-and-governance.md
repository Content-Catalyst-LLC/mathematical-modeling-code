# Validation Ethics and Governance

Validation language can authorize action. Calling a model "validated" without context can create false trust.

## Ethical risks

- treating validation as a universal approval stamp;
- reporting one favorable metric while hiding failure modes;
- ignoring uncertainty and robustness;
- using validation data affected by calibration;
- applying a model outside its scope;
- failing to state who reviewed the model and for what use.

## Responsible practice

- state the intended use;
- preserve validation evidence;
- report multiple diagnostics;
- separate calibration and validation;
- include uncertainty and sensitivity review;
- provide fitness-for-purpose conclusions;
- state use limits clearly.
