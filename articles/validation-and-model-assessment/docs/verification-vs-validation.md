# Verification vs Validation

## Verification

Verification asks whether the model was built correctly.

Examples:

- unit tests;
- known-case checks;
- range checks;
- conservation checks;
- regression tests;
- code review.

## Validation

Validation asks whether the right model was built for the intended purpose.

Examples:

- conceptual review;
- data validation;
- residual diagnostics;
- out-of-sample testing;
- external benchmarks;
- uncertainty and robustness analysis;
- decision-use review.

## Principle

Verification can pass while validation fails. Calibration can succeed while validation fails. These practices must remain distinct.
