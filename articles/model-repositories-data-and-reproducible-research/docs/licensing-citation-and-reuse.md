# Licensing, Citation, and Reuse

## Review questions

- What license applies to code?
- What license applies to data?
- What license applies to documentation?
- How should the repository be cited?
- Which version supports the result?
- Are there data that cannot be redistributed?
- What should not be reused or generalized?

## Principle

Reuse requires legal clarity and interpretive context. A repository should make both visible.
