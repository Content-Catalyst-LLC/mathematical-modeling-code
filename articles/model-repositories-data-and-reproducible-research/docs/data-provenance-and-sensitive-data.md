# Data Provenance and Sensitive Data

## Data provenance questions

- Where did the data come from?
- What license or access restrictions apply?
- What version or date was used?
- What transformations were performed?
- What units and scales apply?
- Which data are raw, processed, synthetic, or restricted?
- Can processed data be regenerated?

## Sensitive data principle

Do not publish sensitive, restricted, private, confidential, or harmful data directly. Use synthetic examples, access notes, redaction, aggregation, or controlled sharing where appropriate.
