# Repository Ethics and Governance

Reproducible repositories support accountability by making model materials inspectable.

## Risks

- data provenance is missing;
- sensitive data are exposed;
- code runs but assumptions are hidden;
- outputs cannot be traced;
- licenses are unclear;
- notebooks depend on hidden execution state;
- results are reused beyond their intended scope.

## Responsible practice

- provide README, metadata, license, and citation notes;
- separate raw, processed, and synthetic data;
- write schemas and data dictionaries;
- create run manifests and output indexes;
- preserve validation checks and model cards;
- state intended use and use limits.
