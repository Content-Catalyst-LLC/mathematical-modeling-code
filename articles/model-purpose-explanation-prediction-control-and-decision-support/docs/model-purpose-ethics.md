# Model Purpose Ethics

Model purpose shapes how outputs enter the world.

## Ethical review questions

- Is the model being used for a more consequential purpose than intended?
- Are users confusing prediction with explanation?
- Are scenarios being presented as probabilities?
- Is an objective function hiding value judgments?
- Is decision support becoming decision substitution?
- Are prohibited uses stated clearly?
- Is uncertainty communicated in the format required by purpose?

## Responsible practice

- state purpose before formal design;
- define supported uses and prohibited uses;
- match validation to purpose;
- report uncertainty by purpose;
- maintain review trails;
- separate model evidence from decision authority.
