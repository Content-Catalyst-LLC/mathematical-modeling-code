# Explanation, Prediction, Control, and Decision Support

## Explanation

Clarifies why system behavior occurs. Prioritizes mechanism, structure, interpretability, and causal plausibility.

## Prediction

Estimates unknown or future values. Prioritizes forecast target, validation horizon, calibration, generalization, and uncertainty.

## Control

Guides action through feedback. Prioritizes state variables, control variables, monitoring, constraints, robustness, and safe operation.

## Decision support

Compares alternatives under uncertainty. Prioritizes consequences, objectives, trade-offs, stakeholder context, uncertainty communication, and accountability.

## Key warning

A model can serve more than one purpose, but each new purpose requires review. Purpose expansion should never happen by convenience alone.
