# Purpose Drift and Prohibited Uses

Purpose drift occurs when a model built for one purpose is used for another without redesign, revalidation, or governance review.

## Common forms

- teaching model used operationally;
- scenario model treated as forecast;
- predictive score treated as causal explanation;
- optimization output treated as policy legitimacy;
- decision-support tool treated as automatic decision authority;
- local model transferred to another domain without validation.
