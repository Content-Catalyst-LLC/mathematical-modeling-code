# Parameter Ranges and Scenario Design

Sensitivity analysis is only as credible as the ranges and scenarios it tests.

## Range design

- Use evidence-based plausible ranges when available.
- Preserve source notes and modeling rationale.
- Avoid arbitrary narrow ranges that make conclusions look robust.
- Avoid unrealistic wide ranges that make all conclusions look unstable.
- Distinguish measurement uncertainty, parameter uncertainty, policy uncertainty, and structural uncertainty.

## Scenario design

- Include baseline, favorable, adverse, and stress conditions.
- Explain why each scenario is credible.
- Avoid designing scenarios only to support a preferred conclusion.
- Connect scenarios to decision consequences and use limits.
