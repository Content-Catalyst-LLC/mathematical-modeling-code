# Sensitivity Ethics and Governance

Sensitivity analysis has ethical stakes because it reveals dependency and fragility.

## Ethical risks

- hiding influential assumptions;
- testing only convenient parameters;
- using arbitrary ranges;
- omitting threshold fragility;
- overstating robustness after narrow checks;
- ignoring structural sensitivity;
- failing to document scenario rationale.

## Responsible practice

- publish parameter ranges and rationale;
- preserve sensitivity rankings;
- report threshold crossings;
- document stress conditions;
- compare plausible model forms when needed;
- communicate where conclusions are robust, fragile, or uncertain.
