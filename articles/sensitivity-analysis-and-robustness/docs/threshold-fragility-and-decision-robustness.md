# Threshold Fragility and Decision Robustness

A model can be sensitive in a way that does not matter for a decision. It can also be insensitive on average but fragile near a threshold.

## Required questions

- How close is the baseline output to the action threshold?
- Which parameters can push the output across the threshold?
- How small a change is enough to reverse the decision?
- Does the recommendation remain stable under stress?
- Do alternative model forms support the same action?

## Principle

Robustness should be interpreted against the decision, not only against output movement.
