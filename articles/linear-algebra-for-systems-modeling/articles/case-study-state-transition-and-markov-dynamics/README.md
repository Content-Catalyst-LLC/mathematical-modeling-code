# Case Study: State Transition and Markov Dynamics

Companion code and reproducible workflows for **Case Study: State Transition and Markov Dynamics** in the **Linear Algebra for Systems Modeling** series.

## Themes

- state spaces, state vectors, transition matrices, and stochastic checks
- Markov chains, matrix powers, multi-step transitions, and stationary distributions
- absorbing states, recurrent and transient behavior, convergence, and eigenvalue interpretation
- stress scenarios, transition perturbations, uncertainty, sensitivity analysis, and validation
- responsible interpretation of memoryless assumptions, time-step choices, and long-run results

## Run

```bash
make smoke
make all
make calculators
make advanced
```
