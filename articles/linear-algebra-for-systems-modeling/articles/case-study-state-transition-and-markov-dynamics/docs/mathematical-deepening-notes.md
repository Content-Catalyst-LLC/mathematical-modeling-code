# Mathematical Deepening Notes

## Required distinctions

- state space versus observed labels
- transition probability versus causal mechanism
- row-stochastic versus column-stochastic convention
- state vector as probability distribution versus count vector
- one-step transition versus multi-step evolution
- stationary distribution versus real-world destiny
- absorbing state versus genuinely irreversible outcome
- Markov property versus history-dependent dynamics
- convergence diagnostic versus validated forecast
- scenario matrix versus operational prediction

## Review checklist

- Document state definitions, transition semantics, time-step meaning, matrix orientation, and boundary scope.
- Verify nonnegative probabilities and row or column sums under the chosen stochastic convention.
- Preserve baseline matrix, stress matrix, initial vector, horizon, stationary approximation, and sensitivity variants.
- Inspect convergence, absorption assumptions, uncertainty, sparse transitions, rare events, hidden heterogeneity, and validation status.
- State interpretation boundaries for memoryless assumptions, long-run behavior, stress scenarios, and decision use.
