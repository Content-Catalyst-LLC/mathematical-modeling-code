# Machine Learning and Linear Algebra

Companion code and reproducible workflows for **Machine Learning and Linear Algebra** in the **Linear Algebra for Systems Modeling** series.

## Themes

- data matrices, features, observations, and labels
- matrix multiplication, affine transformations, and prediction
- least squares, ridge regression, gradients, and loss functions
- regularization, norms, conditioning, scaling, and numerical stability
- PCA, SVD, embeddings, low-rank learning, kernels, and neural layers
- validation, residual diagnostics, distribution shift, and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
