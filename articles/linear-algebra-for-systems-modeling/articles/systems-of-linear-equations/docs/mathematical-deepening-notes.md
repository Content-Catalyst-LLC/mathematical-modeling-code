# Mathematical Deepening Notes

## Required distinctions

- equation listing versus matrix form
- algebraic consistency versus practical feasibility
- unique solution versus certainty
- no solution versus model failure
- infinitely many solutions versus useful flexibility
- homogeneous versus nonhomogeneous systems
- coefficient rank versus augmented rank
- equation count versus independent constraint count
- exact solution versus least-squares approximation

## Review checklist

- Define every equation row.
- Define every unknown variable and whether values may be negative.
- Define the right-hand-side vector and its units.
- Check coefficient rank and augmented rank.
- Classify the solution behavior.
- Review feasibility beyond algebraic consistency.
- Preserve interpretation warnings with solver outputs.
