# Systems of Linear Equations

Companion code and reproducible workflows for **Systems of Linear Equations** in the **Linear Algebra for Systems Modeling** series.

## Themes

- systems of linear equations
- matrix form A x = b
- coefficient matrices
- unknown vectors
- right-hand-side vectors
- augmented matrices
- rank and augmented rank
- consistency
- feasibility
- unique, no, and infinite solutions
- homogeneous and nonhomogeneous systems
- underdetermined and overdetermined systems
- row operations
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
