# Case Study: Dimensionality Reduction in High-Dimensional Data

Companion code and reproducible workflows for **Case Study: Dimensionality Reduction in High-Dimensional Data** in the **Linear Algebra for Systems Modeling** series.

## Themes

- feature matrices, centering, scaling, covariance, and correlation
- projection, subspaces, PCA, SVD, low-rank approximation, and component selection
- explained variance, reconstruction error, noise filtering, rare-pattern preservation, and validation
- visualization, cluster interpretation, leakage control, stability checks, interpretability, and responsible use

## Run

```bash
make smoke
make all
make calculators
make advanced
```
