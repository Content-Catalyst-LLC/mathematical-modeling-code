# Mathematical Deepening Notes

## Required distinctions

- pivot position versus pivot column
- pivot row versus original equation meaning
- rank as pivot count versus model adequacy
- coefficient rank versus augmented rank
- pivot variables versus real-world controllability
- free variables versus missing information
- column-space reachability versus feasibility
- null-space freedom versus practical choice
- exact pivot structure versus numerical tolerance

## Review checklist

- Preserve original row and column labels.
- Record pivot columns and free columns.
- Compare coefficient rank and augmented rank.
- Classify no, unique, or infinitely many solutions.
- Record tolerance and numerical rank decisions.
- Interpret augmented-column pivots as diagnostic conflicts.
- Connect free variables to modeling meaning.
