# Pivot Structure and Solvability

Companion code and reproducible workflows for **Pivot Structure and Solvability** in the **Linear Algebra for Systems Modeling** series.

## Themes

- pivot positions
- pivot rows and pivot columns
- free variables
- rank as pivot count
- coefficient rank and augmented rank
- solvability
- unique, no, and infinite solutions
- column-space reachability
- null-space freedom
- numerical pivoting and tolerance
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
