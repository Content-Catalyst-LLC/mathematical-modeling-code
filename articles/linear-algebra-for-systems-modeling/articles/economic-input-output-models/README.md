# Economic Input-Output Models

Companion code and reproducible workflows for **Economic Input-Output Models** in the **Linear Algebra for Systems Modeling** series.

## Themes

- intersectoral transactions and transaction matrices
- technical coefficients and direct requirements
- final demand and total output vectors
- Leontief-style systems and total requirements
- output multipliers, demand shocks, and scenario analysis
- supply-chain exposure and environmental extensions
- sector classification, aggregation, boundaries, uncertainty, and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
