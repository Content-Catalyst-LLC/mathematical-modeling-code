# Change of Basis and Alternative Representations

Companion code and reproducible workflows for **Change of Basis and Alternative Representations** in the **Linear Algebra for Systems Modeling** series.

## Themes

- basis vectors
- coordinate systems
- change-of-basis matrices
- coordinate recovery
- reconstruction error
- similarity transformations
- invariants
- scaling and normalization
- condition numbers
- representation governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
