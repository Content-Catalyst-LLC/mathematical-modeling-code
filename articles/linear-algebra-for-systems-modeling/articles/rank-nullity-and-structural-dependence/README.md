# Rank, Nullity, and Structural Dependence

Companion code and reproducible workflows for **Rank, Nullity, and Structural Dependence** in the **Linear Algebra for Systems Modeling** series.

## Themes

- rank
- nullity
- rank-nullity theorem
- row rank and column rank
- row space and column space
- null space
- structural dependence
- rank deficiency
- identifiability
- underdetermination
- numerical rank and tolerance
- model governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
