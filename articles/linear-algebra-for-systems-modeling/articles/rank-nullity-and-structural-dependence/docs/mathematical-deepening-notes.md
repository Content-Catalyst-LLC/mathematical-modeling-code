# Mathematical Deepening Notes

## Required distinctions

- rank versus row count or column count
- rank versus model adequacy
- nullity versus uncertainty
- nullity versus useful flexibility
- row dependence versus column dependence
- exact rank versus numerical rank
- rank deficiency versus model failure
- structural dependence versus meaningful conservation structure
- identifiability versus mere solvability

## Review checklist

- Record row meanings and column meanings.
- Compute rank and nullity.
- Record pivot columns and free columns.
- Check whether rank is deficient.
- Interpret null-space freedom.
- Review row and column dependence.
- Document tolerance for numerical rank.
- Connect dependence findings to model purpose.
