# Mathematical Deepening Notes

## Required distinctions

- system versus representation
- matrix as data structure versus matrix as modeling object
- row/column labels versus row/column meaning
- zero as true absence versus zero as missingness
- raw units versus standardized coordinates
- scaling for computation versus scaling for interpretation
- original basis versus transformed basis
- feature inclusion versus omitted structure
- aggregation simplicity versus lost resolution
- representation sensitivity versus numerical sensitivity

## Review checklist

- Document row meaning, column meaning, value meaning, units, zeros, missingness, aggregation, and system boundaries.
- State the coordinate system, basis, scaling, normalization, encoding, and transformation rules.
- Track how representation choices affect norms, rank, sparsity, conditioning, comparability, and interpretation.
- Compare results across multiple reasonable representations where conclusions matter.
- Preserve assumption registers and interpretation warnings as generated outputs.
