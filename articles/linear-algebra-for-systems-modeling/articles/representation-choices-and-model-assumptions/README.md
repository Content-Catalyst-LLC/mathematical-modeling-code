# Representation Choices and Model Assumptions

Companion code and reproducible workflows for **Representation Choices and Model Assumptions** in the **Linear Algebra for Systems Modeling** series.

## Themes

- representation before computation
- rows, columns, values, zeros, missingness, units, and scale
- feature design, categorical encoding, basis choice, and coordinate systems
- aggregation, discretization, spatial and temporal resolution
- network, dynamic-system, and state-space representation choices
- assumption registers, representation sensitivity, and governance
- responsible interpretation of matrices as modeling objects

## Run

```bash
make smoke
make all
make calculators
make advanced
```
