# Mathematical Deepening Notes

## Required distinctions

- matrix as array versus matrix as system representation
- data matrix versus coefficient matrix
- coefficient matrix versus transition matrix
- adjacency matrix versus flow matrix
- row orientation versus column orientation
- zero as absence versus zero as missingness
- sparsity versus missing data
- symmetry versus reciprocal relationships
- rank versus listed variable count
- matrix operation validity versus system interpretation

## Review checklist

- Define matrix role.
- Document row meanings, column meanings, and entry meanings.
- Record shape, units, orientation, and indexing conventions.
- Identify whether zero means absence, no effect, baseline, or missingness.
- Check sparsity, symmetry, and rank.
- Confirm that matrix multiplication and downstream operations match the intended orientation.
