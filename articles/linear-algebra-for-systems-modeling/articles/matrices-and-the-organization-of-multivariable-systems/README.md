# Matrices and the Organization of Multivariable Systems

Companion code and reproducible workflows for **Matrices and the Organization of Multivariable Systems** in the **Linear Algebra for Systems Modeling** series.

## Themes

- matrices
- multivariable systems
- data matrices
- coefficient matrices
- transition matrices
- adjacency matrices
- flow matrices
- block matrices
- sparsity
- symmetry
- rank
- orientation
- row and column metadata
- matrix governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
