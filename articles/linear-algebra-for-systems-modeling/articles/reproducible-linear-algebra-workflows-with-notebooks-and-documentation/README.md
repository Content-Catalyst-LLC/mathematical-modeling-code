# Reproducible Linear Algebra Workflows with Notebooks and Documentation

Companion code and reproducible workflows for **Reproducible Linear Algebra Workflows with Notebooks and Documentation** in the **Linear Algebra for Systems Modeling** series.

## Themes

- notebooks as computational narratives
- scripts, repositories, Makefiles, generated reports, and workflow automation
- matrix construction records, data provenance, metadata, and schemas
- environment control, package versions, numerical backends, and runtime metadata
- random seeds, deterministic workflows, and randomized algorithm disclosure
- validation tests, reference cases, edge cases, residual checks, and diagnostics
- output manifests, reproducible figures, version control, audit trails, and governance
- responsible interpretation beyond reproducible execution

## Run

```bash
make smoke
make all
make calculators
make advanced
```
