# Case Study: Linear Structure in Machine Learning Pipelines

Companion code and reproducible workflows for **Case Study: Linear Structure in Machine Learning Pipelines** in the **Linear Algebra for Systems Modeling** series.

## Themes

- feature matrices, design matrices, target vectors, preprocessing, scaling, encoding, and imputation
- train-test separation, leakage control, linear baselines, ridge regression, and regularization
- projections, embeddings, neural layers, gradients, residuals, evaluation metrics, and drift monitoring
- interpretability, proxy review, bias analysis, validation, documentation, governance, and responsible deployment

## Run

```bash
make smoke
make all
make calculators
make advanced
```
