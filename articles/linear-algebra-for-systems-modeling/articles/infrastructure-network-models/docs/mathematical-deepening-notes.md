# Mathematical Deepening Notes

## Required distinctions

- asset inventory versus infrastructure network
- physical link versus functional dependency
- single-layer network versus multilayer network
- adjacency structure versus incidence structure
- service capacity versus observed service
- redundancy in a graph versus usable redundancy under disruption
- centrality versus criticality
- vulnerability metric versus community consequence
- scenario design versus prediction
- restoration objective versus public priority

## Review checklist

- Define infrastructure scope, layer boundary, and time horizon.
- Define nodes as assets, service areas, facilities, junctions, or institutional entities.
- Define edges as physical links, functional dependencies, access routes, control links, or governance relationships.
- Document capacities, demands, conditions, reliability, exposure, and provenance.
- Distinguish physical, functional, spatial, operational, institutional, and social structure.
- Test disruptions, capacity reductions, dependency failures, and recovery scenarios.
- Review security limitations and social vulnerability interpretation.
