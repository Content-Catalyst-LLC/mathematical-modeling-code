# Overdetermined Systems and Least Squares Thinking

Companion code and reproducible workflows for **Overdetermined Systems and Least Squares Thinking** in the **Linear Algebra for Systems Modeling** series.

## Themes

- overdetermined systems
- residual vectors
- least-squares approximation
- projection onto column space
- normal equations
- rank and identifiability
- regression and calibration
- weighted and constrained least squares
- QR and SVD diagnostics
- solver-choice governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
