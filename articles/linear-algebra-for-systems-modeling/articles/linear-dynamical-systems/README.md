# Linear Dynamical Systems

Companion code and reproducible workflows for **Linear Dynamical Systems** in the **Linear Algebra for Systems Modeling** series.

## Themes

- state vectors
- update matrices
- discrete-time dynamics
- matrix powers
- trajectories
- equilibria and fixed points
- eigenvalue stability
- forced and affine dynamics
- state-space representation
- linearization
- simulation and iteration
- numerical diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
