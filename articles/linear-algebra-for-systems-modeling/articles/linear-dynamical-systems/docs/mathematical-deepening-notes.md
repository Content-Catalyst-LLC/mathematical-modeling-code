# Mathematical Deepening Notes

## Required distinctions

- state vector versus observed output
- update matrix versus empirical correlation
- matrix powers versus continuous-time matrix exponentials
- homogeneous dynamics versus forced dynamics
- equilibrium existence versus stability near equilibrium
- spectral-radius stability versus practical safety
- structural linearity versus local linear approximation
- simulated trajectory versus validated forecast

## Review checklist

- Define every state variable.
- Document units and scaling.
- State the time step.
- Define the update matrix source.
- Record the initial state.
- Simulate trajectories over a justified horizon.
- Report eigenvalues and spectral radius.
- Check state norms over time.
- Review equilibrium or fixed-point claims.
- Test sensitivity to plausible matrix perturbations.
- Check whether simulated states remain domain-valid.
