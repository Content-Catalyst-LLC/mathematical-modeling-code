# Mathematical Deepening Notes

## Required distinctions

- matrix arithmetic as formal operation versus modeling claim
- shape compatibility versus semantic compatibility
- matrix addition versus matrix multiplication
- scalar multiplication versus unit conversion
- weighted combination versus objective aggregation
- elementwise operation versus linear transformation
- residual matrix versus causal explanation
- normalization versus neutral preprocessing

## Review checklist

- Confirm shapes before addition or subtraction.
- Confirm row labels, column labels, units, and orientation.
- Document the meaning of every scalar and every weight.
- Preserve traceability from combined matrices to source matrices.
- Report component matrices when composite results may hide tradeoffs.
- Run sensitivity checks for contested weights.
