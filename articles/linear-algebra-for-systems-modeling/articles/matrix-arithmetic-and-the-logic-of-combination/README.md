# Matrix Arithmetic and the Logic of Combination

Companion code and reproducible workflows for **Matrix Arithmetic and the Logic of Combination** in the **Linear Algebra for Systems Modeling** series.

## Themes

- matrix addition
- matrix subtraction
- scalar multiplication
- linear combinations
- weighted combinations
- scenario matrices
- elementwise operations
- compatibility diagnostics
- row and column alignment
- units and scaling
- normalization
- matrix arithmetic governance
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
