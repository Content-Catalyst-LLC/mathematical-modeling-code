# Leontief Systems and Intersectoral Dependence

Companion code and reproducible workflows for **Leontief Systems and Intersectoral Dependence** in the **Linear Algebra for Systems Modeling** series.

## Themes

- input-output balance and technical coefficients
- net requirements and the Leontief system
- Leontief inverse, total requirements, and multipliers
- direct and indirect dependence across sectors
- productivity checks, spectral radius, and feasibility
- demand shocks, environmental extensions, conditioning, and sensitivity
- responsible interpretation of fixed-coefficient matrix systems

## Run

```bash
make smoke
make all
make calculators
make advanced
```
