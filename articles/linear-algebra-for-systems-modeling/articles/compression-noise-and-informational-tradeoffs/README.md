# Compression, Noise, and Informational Tradeoffs

Companion code and reproducible workflows for **Compression, Noise, and Informational Tradeoffs** in the **Linear Algebra for Systems Modeling** series.

## Themes

- compression as representation choice
- signal, noise, residuals, and weak-signal review
- low-rank approximation, SVD compression, and PCA compression
- retained energy, discarded energy, reconstruction error, and compression ratio
- sparse representation, denoising, filtering, and information loss
- validation, rank sensitivity, residual diagnostics, and responsible simplification

## Run

```bash
make smoke
make all
make calculators
make advanced
```
