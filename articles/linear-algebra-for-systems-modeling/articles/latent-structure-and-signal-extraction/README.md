# Latent Structure and Signal Extraction

Companion code and reproducible workflows for **Latent Structure and Signal Extraction** in the **Linear Algebra for Systems Modeling** series.

## Themes

- observed matrices, latent scores, loadings, and residuals
- signal, noise, residuals, and low-rank structure
- SVD, PCA, factor models, NMF, ICA, and embeddings
- latent spaces, signal extraction, residual diagnostics, and anomaly scoring
- stability validation, rank sensitivity, and method assumptions
- responsible interpretation of hidden components and extracted signals

## Run

```bash
make smoke
make all
make calculators
make advanced
```
