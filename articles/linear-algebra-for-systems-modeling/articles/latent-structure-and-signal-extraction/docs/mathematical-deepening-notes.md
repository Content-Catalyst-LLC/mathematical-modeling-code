# Mathematical Deepening Notes

## Required distinctions

- observed data versus inferred latent structure
- signal versus noise versus residuals
- latent scores versus loadings
- low-rank approximation versus real system mechanism
- SVD components versus causes
- PCA variance directions versus latent factors
- factor models versus matrix factorization
- anomaly versus error
- residuals as waste versus residuals as omitted structure
- embeddings as representations versus explanations

## Review checklist

- Define the observed matrix, row meaning, column meaning, units, and missing-data handling.
- Document preprocessing, scaling, centering, transformations, and filtering.
- State the extraction method and the type of latent structure it can represent.
- Report rank, retained signal ratio, latent scores, loadings, reconstructed signal, and residuals.
- Review residuals by observation, variable, time, location, and subgroup when relevant.
- Validate stability across rank choices, preprocessing, samples, seeds, and time windows.
- Avoid treating latent scores as unreviewed proxies for people, places, capacity, value, or risk.
