# Mathematical Deepening Notes

## Required distinctions

- large matrix versus better model
- dense storage versus real interaction density
- sparse structure versus omitted weak relationships
- residual reduction versus validation evidence
- iterative convergence versus exact solution
- randomized approximation versus full decomposition
- matrix-free operator versus explicit matrix
- runtime success versus numerical reliability
- scalable output versus responsible interpretation

## Review checklist

- Define matrix shape, density, storage format, memory footprint, and operation counts.
- Document direct, iterative, randomized, sparse, distributed, or matrix-free method.
- Report residual norms, convergence tolerance, iterations, and stopping criteria.
- Report conditioning, numerical precision, stability warnings, and validation checks.
- Document approximation method, random seed, sampling/sketching design, and error diagnostics.
