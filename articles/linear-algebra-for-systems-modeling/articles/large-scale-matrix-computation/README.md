# Large-Scale Matrix Computation

Companion code and reproducible workflows for **Large-Scale Matrix Computation** in the **Linear Algebra for Systems Modeling** series.

## Themes

- matrix shape, density, memory footprint, and data movement
- dense, sparse, block, distributed, and matrix-free representation
- matrix-vector products, matrix-matrix products, and operation cost
- direct factorization, iterative solvers, residuals, and preconditioning
- eigenvalue approximation, truncated SVD, and randomized linear algebra
- conditioning, numerical precision, convergence diagnostics, and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
