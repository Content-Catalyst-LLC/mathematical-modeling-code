# Advanced State-Space Geometry Review

- **inner_product_definition** (required): State whether geometry is Euclidean, weighted, covariance-aware, or domain-specific.
- **norm_choice** (required): Document which norm measures residuals, error, distance, or convergence.
- **scaling_units** (required): Check whether coordinate units make distance meaningful.
- **weights_review** (required): Justify weights as risk, cost, uncertainty, reliability, priority, or energy.
- **covariance_review** (recommended): Use covariance-aware distance only when covariance estimates are reliable.
- **translation_back** (recommended): Translate normalized or weighted distances back into domain terms.
