# Mathematical Deepening Notes

## Required distinctions

- diagonalizable versus not diagonalizable
- eigenvalue availability versus eigenvector-basis availability
- original coordinates versus modal coordinates
- diagonal matrix behavior versus original variable behavior
- spectral radius versus transient dynamics
- defective matrices versus repeated eigenvalues
- orthogonal diagonalization versus general diagonalization
- reconstruction error versus substantive model meaning

## Review checklist

- Define the matrix and its units.
- Document scaling and time step.
- Confirm enough independent eigenvectors exist.
- Report reconstruction error.
- Report eigenpair residuals.
- Report or estimate condition number of P.
- Review spectral gap, nonnormality, and symmetry.
- Translate modal coordinates back into system terms.
