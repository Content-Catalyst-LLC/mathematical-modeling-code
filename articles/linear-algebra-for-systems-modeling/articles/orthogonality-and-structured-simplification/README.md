# Orthogonality and Structured Simplification

Companion code and reproducible workflows for **Orthogonality and Structured Simplification** in the **Linear Algebra for Systems Modeling** series.

## Themes

- orthogonality
- dot products
- orthogonal complements
- orthonormal bases
- projection residuals
- Gram-Schmidt
- QR decomposition
- orthogonal matrices
- numerical stability
- structured simplification
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
