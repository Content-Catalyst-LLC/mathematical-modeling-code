# Case Study: Economic Input-Output Analysis

Companion code and reproducible workflows for **Case Study: Economic Input-Output Analysis** in the **Linear Algebra for Systems Modeling** series.

## Themes

- transaction matrices, technical coefficients, final demand, and gross output
- Leontief matrices, Leontief inverses, total requirements, and multipliers
- final-demand shock scenarios and sector output changes
- supply-chain exposure, imports, leakage, environmental and social extensions
- aggregation, data quality, table vintage, uncertainty, validation, and responsible interpretation
- numerical checks for invertibility, conditioning, residuals, and plausibility

## Run

```bash
make smoke
make all
make calculators
make advanced
```
