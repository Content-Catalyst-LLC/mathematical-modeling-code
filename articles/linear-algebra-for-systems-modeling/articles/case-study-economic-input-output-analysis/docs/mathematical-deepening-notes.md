# Mathematical Deepening Notes

## Required distinctions

- transaction matrix versus technical coefficient matrix
- gross output versus final demand
- direct requirements versus total requirements
- Leontief inverse versus economic prediction
- output multiplier versus welfare or value
- domestic requirements versus total requirements
- sector-average coefficients versus firm-level supply chains
- solvability versus economic feasibility
- fixed coefficients versus substitution and capacity constraints
- scenario analysis versus forecast

## Review checklist

- Document sector classification, table year, price basis, domestic/import boundary, and final-demand definitions.
- Preserve transaction matrices, technical coefficient matrices, Leontief matrices, total requirements, multipliers, and demand-shock scenarios.
- Inspect invertibility, conditioning, residuals, coefficient plausibility, nonnegative outputs, and capacity plausibility.
- Test sensitivity to demand shocks, coefficient uncertainty, import shares, aggregation levels, and extension factors.
- State interpretation boundaries for multipliers, output requirements, supply-chain exposure, environmental extensions, and policy claims.
