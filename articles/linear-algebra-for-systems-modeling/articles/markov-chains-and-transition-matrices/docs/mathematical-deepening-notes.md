# Mathematical Deepening Notes

## Required distinctions

- state definitions versus observed labels
- row-stochastic versus column-stochastic convention
- one-step transition versus multi-step transition
- transition probability versus transition count
- stationary distribution versus convergence
- steady-state existence versus uniqueness
- absorbing state versus transient state
- irreducibility versus reducibility
- periodicity versus aperiodicity
- long-run distribution versus desirable outcome

## Review checklist

- Define every state.
- Document the time step.
- State row or column convention.
- Check nonnegativity.
- Check row or column sums.
- Verify initial distribution sums to one.
- Compute one-step and multi-step forecasts.
- Estimate or solve for stationary distribution.
- Review absorbing states, reducibility, and periodicity.
- Validate transition probabilities against observed data where possible.
