# Markov Chains and Transition Matrices

Companion code and reproducible workflows for **Markov Chains and Transition Matrices** in the **Linear Algebra for Systems Modeling** series.

## Themes

- Markov chains
- transition matrices
- stochastic matrices
- row and column conventions
- state vectors
- matrix powers
- steady-state distributions
- absorbing states
- reducibility and periodicity
- convergence diagnostics
- transition-matrix validation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
