# Linear Transformations and Model Behavior

Companion code and reproducible workflows for **Linear Transformations and Model Behavior** in the **Linear Algebra for Systems Modeling** series.

## Themes

- linear transformations
- matrix action
- system states
- domain and codomain
- image and kernel
- rank and nullity
- transformed basis vectors
- amplification and damping
- state-transition thinking
- sensitivity diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
