# Mathematical Deepening Notes

## Required distinctions

- matrix as coefficient table versus matrix as transformation
- domain versus codomain
- image versus codomain
- kernel versus null space
- rank as reachable output dimension
- nullity as invisible input dimension
- linearity as mathematical property and modeling assumption
- transformation behavior versus causal behavior
- amplification under matrix action versus model validity

## Review checklist

- Document row and column meanings.
- Record domain and codomain dimensions.
- Compute transformed examples.
- Check rank and nullity.
- Review whether linearity is plausible.
- Report amplification or damping for representative states.
- Document units, scaling, sensitivity, and conditioning.
