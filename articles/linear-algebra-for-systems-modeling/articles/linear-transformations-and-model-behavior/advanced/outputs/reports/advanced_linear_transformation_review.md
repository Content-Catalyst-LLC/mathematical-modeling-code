# Advanced Linear Transformation Review

- **linearity_assumption** (required): Document why addition and scalar multiplication are acceptable for the modeled context.
- **domain_codomain_review** (required): Record input and output dimensions and meanings.
- **image_kernel_review** (required): Document reachable outputs and invisible input directions.
- **basis_behavior_review** (required): Interpret columns as transformed basis directions when meaningful.
- **rank_nullity_review** (required): Connect rank and nullity to transformation behavior.
- **sensitivity_review** (recommended): Assess amplification, damping, scaling, and conditioning before decision use.
