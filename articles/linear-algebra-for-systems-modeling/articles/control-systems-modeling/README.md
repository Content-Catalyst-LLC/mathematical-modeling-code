# Control Systems Modeling

Companion code and reproducible workflows for **Control Systems Modeling** in the **Linear Algebra for Systems Modeling** series.

## Themes

- state-space representation
- inputs and outputs
- feedback matrices
- open-loop and closed-loop dynamics
- eigenvalues and poles
- continuous-time and discrete-time control
- controllability and observability
- pole placement and stabilization
- optimal control intuition
- constraints and actuator saturation
- robustness and uncertainty
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
