# Mathematical Deepening Notes

## Required distinctions

- state versus input versus output
- open-loop versus closed-loop dynamics
- state feedback versus output feedback
- controllability versus stabilizability
- observability versus detectability
- pole placement versus robust control
- mathematical input channel versus real-world authority
- optimal control objective versus domain value judgment
- nominal stability versus robustness under uncertainty

## Review checklist

- Define state variables, inputs, outputs, units, and time model.
- Document A, B, C, and D matrix sources.
- Compute open-loop and closed-loop eigenvalues.
- Check continuous-time or discrete-time stability with the correct rule.
- Compute controllability and observability ranks.
- Review conditioning of controllability and observability matrices.
- Track simulated trajectories and input effort.
- Check actuator saturation, state constraints, delay, and noise.
- Document control objectives and value choices.
- Test sensitivity to plausible model perturbations.
