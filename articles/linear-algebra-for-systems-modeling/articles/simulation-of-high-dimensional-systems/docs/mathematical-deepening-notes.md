# Mathematical Deepening Notes

## Required distinctions

- state vector versus real system state
- simulation trajectory versus observation
- ensemble distribution versus future certainty
- covariance matrix versus full uncertainty
- sparse operator versus complete dependency structure
- reduced-order model versus complete model
- calibration fit versus validation evidence
- Monte Carlo output versus causal proof
- simulated scenario versus implementation reality

## Review checklist

- Define state variables, units, boundary, resolution, and time step.
- Document transition rule, parameter space, random seed, uncertainty distributions, and covariance assumptions.
- Report state dimension, ensemble size, horizon, sparse structure, and summary outputs.
- Report dimensionality reduction method and information-loss diagnostics.
- Run sensitivity tests for parameters, initial states, covariance, and scenarios.
- Document validation evidence and interpretation limits.
