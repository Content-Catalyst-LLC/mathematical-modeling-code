# Simulation of High-Dimensional Systems

Companion code and reproducible workflows for **Simulation of High-Dimensional Systems** in the **Linear Algebra for Systems Modeling** series.

## Themes

- high-dimensional state vectors and parameter spaces
- transition matrices, sparse operators, and system evolution
- simulation ensembles and Monte Carlo experiments
- correlated uncertainty and covariance structure
- dimensionality reduction, SVD diagnostics, and reduced-order summaries
- sensitivity analysis, uncertainty quantification, validation, and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
