# Mathematical Deepening Notes

## Required distinctions

- adjacency matrix versus incidence matrix
- edge existence versus edge capacity
- weight strength versus weight cost
- directed versus undirected connections
- degree centrality versus eigenvector centrality
- connectivity versus reachability
- path existence versus feasible flow
- graph visualization versus graph structure
- stress test scenario versus validated failure prediction
- centrality score versus real-world importance

## Review checklist

- Document node semantics, edge semantics, weight semantics, directionality, and boundary scope.
- Preserve adjacency matrices, incidence matrices, degree vectors, Laplacians, transition matrices, and stress-test variants.
- Inspect connectivity, components, centrality, vulnerability, and spectral diagnostics.
- Flag uncertain edges, missing edges, temporal mismatch, aggregation, and visualization limits.
- State interpretation boundaries for centrality, flow, vulnerability, diffusion, and transition claims.
