# Case Study: Network System Modeling

Companion code and reproducible workflows for **Case Study: Network System Modeling** in the **Linear Algebra for Systems Modeling** series.

## Themes

- nodes, edges, weights, directionality, and system boundaries
- adjacency matrices, incidence matrices, degree vectors, Laplacians, and transition matrices
- connectivity, reachability, centrality, spectral diagnostics, and vulnerability analysis
- edge-removal and node-removal stress testing
- data quality, missing edges, weight semantics, visualization limits, and governance
- responsible interpretation of network metrics as representation-dependent evidence

## Run

```bash
make smoke
make all
make calculators
make advanced
```
