# Eigenvalues, Eigenvectors, and System Modes

Companion code and reproducible workflows for **Eigenvalues, Eigenvectors, and System Modes** in the **Linear Algebra for Systems Modeling** series.

## Themes

- eigenvalues
- eigenvectors
- system modes
- spectral radius
- dominant modes
- stability
- growth and decay
- characteristic equations
- eigenpair residuals
- network centrality
- Markov steady states
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
