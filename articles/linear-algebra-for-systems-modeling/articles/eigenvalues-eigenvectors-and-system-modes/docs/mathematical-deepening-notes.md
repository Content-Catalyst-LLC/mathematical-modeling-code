# Mathematical Deepening Notes

## Required distinctions

- eigenvalue versus eigenvector
- eigenvector direction versus vector magnitude
- eigenspace versus individual eigenvector
- algebraic multiplicity versus geometric multiplicity
- spectral radius versus dominant eigenvalue
- asymptotic stability versus transient behavior
- diagonalizable matrix versus defective matrix
- numerical residual versus substantive mode meaning
- Markov steady state versus causal equilibrium

## Review checklist

- Define the matrix and its units.
- Document scaling and time step.
- Report eigenvalues and spectral radius.
- Identify dominant modes and spectral gaps.
- Compute or document eigenpair residuals.
- Review nonnormality, conditioning, repeated eigenvalues, and mode sensitivity.
- Interpret modes only within the model's domain assumptions.
