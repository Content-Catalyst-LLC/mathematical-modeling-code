# Decomposition Workflows for Systems Analysis

Companion code and reproducible workflows for **Decomposition Workflows for Systems Analysis** in the **Linear Algebra for Systems Modeling** series.

## Themes

- LU factorization, pivoting, triangular solves, and residual diagnostics
- QR decomposition, orthogonalization, least-squares stability, and rank review
- Cholesky factorization for symmetric positive definite systems
- eigenvalue decomposition, Schur decomposition, modes, and stability analysis
- SVD, singular spectra, rank, conditioning, low-rank approximation, and PCA
- sparse factorization, fill-in, ordering, preconditioning, and scalability
- decomposition governance, reconstruction error, approximation limits, and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
