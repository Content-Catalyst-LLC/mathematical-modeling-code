# Mathematical Deepening Notes

## Required distinctions

- decomposition formula versus decomposition workflow
- solver convenience versus matrix-structure match
- factorization success versus numerical reliability
- eigenvectors versus stable spectral analysis
- singular values versus substantive meaning
- rank estimate versus exact rank
- low-rank approximation versus complete system representation
- sparse factorization versus preserved sparsity
- reconstruction error versus interpretive validity

## Review checklist

- Document matrix shape, source, units, scaling, sparsity, symmetry, definiteness, and conditioning.
- Choose decomposition based on task: solve, least squares, modes, rank, approximation, compression, or scalability.
- Report reconstruction error, residual norm, orthogonality error, condition number, rank tolerance, and singular spectrum where relevant.
- Record pivoting, ordering, factorization type, approximation rank, solver method, package versions, and output schemas.
- Interpret factors through system meaning, not as automatic causal or institutional categories.
