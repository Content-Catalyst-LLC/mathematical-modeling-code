# Mathematical Deepening Notes

## Required distinctions

- span versus feasible reachability
- linear independence versus substantive independence
- linear dependence versus uselessness
- basis versus best representation
- rank versus model adequacy
- coordinates versus original system meaning
- overcomplete representation versus redundancy error
- undercomplete representation versus simplification
- numerical rank versus exact rank
- mathematical validity versus systems validity

## Review checklist

- Define each vector and its systems meaning.
- Document what the vector set is claimed to span.
- Record coefficient meanings and constraints.
- Check dependence, independence, and rank.
- Identify whether the vector set is overcomplete, undercomplete, or a basis.
- Document basis choice and coordinate interpretation.
- Record numerical tolerance and scaling choices for rank.
- Distinguish span inside the mathematical model from feasible system reachability.
- Identify what directions remain outside the current representation.
