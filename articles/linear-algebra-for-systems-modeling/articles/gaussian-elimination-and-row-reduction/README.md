# Gaussian Elimination and Row Reduction

Companion code and reproducible workflows for **Gaussian Elimination and Row Reduction**.

## Themes

- Gaussian elimination
- elementary row operations
- augmented matrices
- echelon form and reduced row echelon form
- pivots and free variables
- rank and consistency
- redundancy and contradiction
- numerical tolerance
- feasibility review

## Run

```bash
make smoke
make all
make calculators
make advanced
```
