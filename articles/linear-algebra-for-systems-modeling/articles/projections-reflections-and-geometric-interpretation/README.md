# Projections, Reflections, and Geometric Interpretation

Companion code and reproducible workflows for **Projections, Reflections, and Geometric Interpretation** in the **Linear Algebra for Systems Modeling** series.

## Themes

- projection matrices
- residual vectors
- reflection matrices
- geometric interpretation
- least-squares geometry
- idempotence, symmetry, involution, and length preservation
- operator diagnostics
- responsible systems modeling

## Run

```bash
make smoke
make all
make calculators
make advanced
```
