# Mathematical Deepening Notes

## Required distinctions

- projection versus reflection
- retained component versus residual component
- orthogonal projection versus oblique projection
- projection matrix versus residual operator
- distance preservation versus information loss
- idempotence versus involution
- standard Euclidean geometry versus weighted geometry
- least-squares approximation versus exact solution

## Review checklist

- Document target subspace and its meaning.
- Compute projected vector and residual vector.
- Check residual norm.
- Check idempotence error for projection.
- Check symmetry error for orthogonal projection.
- Check involution and length-preservation errors for reflection.
- Review rank, conditioning, units, scaling, and chosen inner product.
