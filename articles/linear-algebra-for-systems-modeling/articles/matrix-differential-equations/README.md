# Matrix Differential Equations

Companion code and reproducible workflows for **Matrix Differential Equations** in the **Linear Algebra for Systems Modeling** series.

## Themes

- state vectors and derivative vectors
- continuous-time linear systems
- system matrices as rate operators
- matrix exponentials
- eigenvalue real-part stability
- diagonalization and modal solutions
- forced response and equilibrium
- numerical integration and stiffness
- state-space modeling
- local linearization
- solver diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
