# Mathematical Deepening Notes

## Required distinctions

- state vector versus derivative vector
- continuous-time generator versus discrete-time update matrix
- matrix exponential versus ordinary matrix powers
- eigenvalue real parts versus eigenvalue magnitudes
- homogeneous response versus forced response
- equilibrium existence versus equilibrium stability
- analytic solution versus numerical integration
- stable eigenvalues versus practical safety
- structural linearity versus local Jacobian approximation

## Review checklist

- Define state variables, units, and time units.
- Document the system matrix source.
- Confirm the matrix is interpreted as a continuous-time rate operator.
- Compute eigenvalues and real parts.
- Classify continuous-time stability.
- Review matrix exponential or solver method.
- Check stiffness and step-size sensitivity.
- Review equilibrium or steady-state claims.
- Validate constraints such as nonnegativity, capacity, or conservation.
- State whether linearity is structural, local, empirical, or exploratory.
