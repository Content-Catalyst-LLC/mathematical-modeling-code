# Mathematical Deepening Notes

## Required distinctions

- dimension versus number of listed variables
- solution space versus one computed solution
- rank versus equation count
- nullity versus error
- free variables versus missing information
- consistency versus feasibility
- unique solution versus justified certainty
- overdetermined versus inconsistent
- underdetermined versus useless
- dimension reduction versus adequate simplification
- mathematical solution versus admissible system state

## Review checklist

- Define each unknown variable and each equation.
- Document the meaning of the coefficient matrix.
- Record rank, nullity, numerical tolerance, and method.
- Identify free variables and their systems meaning.
- Distinguish homogeneous and nonhomogeneous structure.
- Check consistency before interpreting solution type.
- Add feasibility constraints when real-world admissibility matters.
- Identify whether additional assumptions, data, priors, or objectives are needed.
