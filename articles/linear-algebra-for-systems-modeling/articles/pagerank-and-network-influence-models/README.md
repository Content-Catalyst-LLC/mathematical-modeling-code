# PageRank and Network Influence Models

Companion code and reproducible workflows for **PageRank and Network Influence Models** in the **Linear Algebra for Systems Modeling** series.

## Themes

- directed graphs and influence
- adjacency matrices and stochastic transition matrices
- Markov chains and random walks
- stationary distributions and eigenvectors
- damping, teleportation, and dangling nodes
- PageRank, personalized PageRank, and weighted influence
- convergence diagnostics and power iteration
- sparse computation and rank sensitivity
- ranking governance and interpretation warnings

## Run

```bash
make smoke
make all
make calculators
make advanced
```
