# Mathematical Deepening Notes

## Required distinctions

- directed graph versus undirected graph
- adjacency matrix versus stochastic transition matrix
- row-stochastic convention versus column-stochastic convention
- degree centrality versus PageRank
- eigenvector centrality versus damped PageRank
- raw link structure versus normalized influence flow
- dangling node versus sink component
- teleportation vector versus personalization profile
- convergence residual versus rank certainty
- ranking score versus substantive authority

## Review checklist

- Define ranked nodes and graph boundary.
- Define directed-edge meaning and direction convention.
- Document transition-matrix normalization.
- Handle dangling nodes explicitly.
- State damping factor and teleportation vector.
- Report convergence tolerance, iteration count, and residuals.
- Compare PageRank with degree and other centrality measures.
- Run sensitivity tests for edge perturbation, weight perturbation, damping changes, and boundary changes.
- Document data provenance and manipulation risks.
