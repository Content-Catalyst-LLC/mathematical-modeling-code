# Mathematical Deepening Notes

## Required distinctions

- vector versus scalar
- vector component versus system meaning
- matrix shape versus matrix interpretation
- coefficient matrix versus transition matrix
- adjacency matrix versus weighted relationship matrix
- rank versus number of variables
- determinant versus system meaning
- eigenvalue magnitude versus responsible stability claim
- decomposition component versus real-world category
- numerical result versus modeled relationship

## Review checklist

- Define each vector component and its units.
- Define each matrix entry and what relationship it represents.
- Record row and column ordering.
- Document scaling, normalization, and measurement assumptions.
- Check rank and dependency when solvability matters.
- Record determinant only when square-matrix interpretation is meaningful.
- Interpret eigenvalues only within a justified transformation or dynamic model.
- Use decompositions as structured approximations, not automatic explanations.
- Preserve warnings about conditioning, scale, omitted variables, and model scope.
