# Mathematical Deepening Notes

## Required distinctions

- sparse matrix versus small matrix
- computational zero versus structural zero
- absent relationship versus unknown relationship
- thresholded weak value versus true zero
- sparse efficiency versus valid representation
- low density versus useful sparsity pattern
- direct sparse solve versus fill-in risk
- iterative convergence versus validated solution
- storage savings versus interpretive completeness

## Review checklist

- Define matrix shape, nonzero count, density, storage format, and sparsity pattern.
- Document what zeros mean in the modeled system.
- Report threshold rules and test sensitivity to threshold changes.
- Report degree distribution, connected components, and structural warnings when the sparse matrix is graph-like.
- Document solver method, residual norms, preconditioning, fill-in risk, and convergence behavior.
- Interpret sparse outputs through structure, omissions, diagnostics, and validation evidence.
