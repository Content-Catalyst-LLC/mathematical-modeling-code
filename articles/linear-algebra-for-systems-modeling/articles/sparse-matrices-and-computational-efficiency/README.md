# Sparse Matrices and Computational Efficiency

Companion code and reproducible workflows for **Sparse Matrices and Computational Efficiency** in the **Linear Algebra for Systems Modeling** series.

## Themes

- sparse representation, nonzero structure, and density
- coordinate, CSR, CSC, DIA, and block sparse storage
- graph matrices, adjacency matrices, incidence matrices, and Laplacians
- sparse matrix-vector products and sparse linear systems
- fill-in, ordering, iterative solvers, preconditioning, and residual diagnostics
- zero interpretation, thresholding, validation, and responsible sparse computation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
