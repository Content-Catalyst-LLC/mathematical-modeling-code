# Dimensionality Reduction Techniques

Companion code and reproducible workflows for **Dimensionality Reduction Techniques** in the **Linear Algebra for Systems Modeling** series.

## Themes

- feature selection and feature extraction
- PCA, SVD, and low-rank approximation
- random projection and sketching
- manifold learning and embeddings
- reconstruction error and information loss
- distance distortion and neighborhood preservation
- rank selection and target-dimension choice
- validation, parameter sensitivity, and reduction governance

## Run

```bash
make smoke
make all
make calculators
make advanced
```
