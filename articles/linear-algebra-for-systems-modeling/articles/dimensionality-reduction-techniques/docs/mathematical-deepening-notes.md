# Mathematical Deepening Notes

## Required distinctions

- feature selection versus feature extraction
- projection versus embedding
- original space versus reduced space
- variance preservation versus distance preservation
- reconstruction error versus decision relevance
- global geometry versus local neighborhood preservation
- linear reduction versus nonlinear reduction
- deterministic decomposition versus randomized projection
- low-rank approximation versus faithful system representation
- reduced coordinates versus causes or categories

## Review checklist

- Define original matrix rows, columns, units, weights, and missing-data handling.
- Document preprocessing, scaling, centering, normalization, and transformations.
- State the reduction method and the structure it is intended to preserve.
- Report target dimension, random seed, parameters, and tolerance.
- Report explained variance, reconstruction error, distance distortion, or neighborhood preservation as appropriate.
- Validate the reduced representation against the systems question and downstream use.
- Review residuals, local errors, rare cases, and subgroup visibility.
