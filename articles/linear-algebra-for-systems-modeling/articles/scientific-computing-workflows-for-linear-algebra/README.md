# Scientific Computing Workflows for Linear Algebra

Companion code and reproducible workflows for **Scientific Computing Workflows for Linear Algebra** in the **Linear Algebra for Systems Modeling** series.

## Themes

- matrix construction, schema design, units, scaling, and provenance
- dense, sparse, structured, distributed, and matrix-free representations
- BLAS, LAPACK, numerical backends, language bindings, and library defaults
- memory layout, data movement, row-major and column-major storage
- solver selection, tolerances, residuals, conditioning, and convergence
- testing, validation, reference cases, edge cases, and diagnostic reporting
- reproducibility, environment control, pipeline automation, and governance

## Run

```bash
make smoke
make all
make calculators
make advanced
```
