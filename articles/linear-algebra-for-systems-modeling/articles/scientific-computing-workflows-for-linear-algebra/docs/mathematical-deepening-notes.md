# Mathematical Deepening Notes

## Required distinctions

- mathematical formula versus computational workflow
- matrix construction versus matrix computation
- dense storage versus sparse storage versus matrix-free operator
- algorithmic cost versus memory movement cost
- solver return value versus diagnostic evidence
- residual tolerance versus substantive model validity
- package default versus documented method choice
- reproducible notebook versus reproducible workflow
- performance demonstration versus scalable scientific computation

## Review checklist

- Document matrix source, schema, shape, units, zeros, scaling, missingness, and provenance.
- Record representation, storage format, precision, solver, tolerance, numerical backend, threading, and package versions.
- Save residuals, condition estimates, convergence histories, performance metrics, validation checks, and interpretation warnings.
- Include reference cases, edge cases, and synthetic examples for testing.
- Keep outputs, logs, reports, schemas, metadata, and generated artifacts under versioned workflow control.
