# Mathematical Deepening Notes

## Required distinctions

- mathematical operation versus programming syntax
- matrix multiplication versus elementwise multiplication
- vector versus row matrix versus column matrix
- data frame versus numerical matrix
- dense array versus sparse storage
- zero-based versus one-based indexing
- successful execution versus validated computation
- cross-language agreement versus model validity
- data exchange versus metadata preservation

## Review checklist

- State the mathematical intent before language-specific implementation.
- Assert matrix and vector shapes before and after major operations.
- Document indexing convention, multiplication operator, elementwise operator, and broadcasting rules.
- Record data type, precision, storage format, solver method, and package versions.
- Check residuals, condition numbers, reconstruction error, and tolerances.
- Preserve row identifiers, column identifiers, units, metadata, missingness rules, and assumptions across languages.
