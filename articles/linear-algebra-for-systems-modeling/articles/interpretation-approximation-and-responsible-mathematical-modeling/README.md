# Interpretation, Approximation, and Responsible Mathematical Modeling

Companion code and reproducible workflows for **Interpretation, Approximation, and Responsible Mathematical Modeling** in the **Linear Algebra for Systems Modeling** series.

## Themes

- interpretation boundaries, claim types, and evidence boundaries
- approximation error, numerical error, data uncertainty, and interpretive uncertainty
- assumption registers, model purpose, validation status, and governance warnings
- residual diagnostics, condition checks, sensitivity review, and scale review
- causal caution, decision support, auditability, accountability, and responsible communication
- responsible use of linear algebra outputs in systems modeling workflows

## Run

```bash
make smoke
make all
make calculators
make advanced
```
