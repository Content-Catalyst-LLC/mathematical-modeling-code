# Mathematical Deepening Notes

## Required distinctions

- stationary distribution versus limiting distribution
- convergence versus existence of a stationary distribution
- initial-condition fading versus initial-condition persistence
- irreducible systems versus reducible systems
- absorbing states versus closed communicating classes
- periodic cycling versus simple convergence
- mathematical long run versus practical decision horizon
- steady behavior versus desirable behavior
- fixed transition rule versus time-varying transition structure

## Review checklist

- Define states and time step.
- State row or column convention.
- Check stochastic validity.
- Compute matrix powers over relevant horizons.
- Estimate or solve stationary distribution.
- Compare multiple initial distributions.
- Measure convergence distance.
- Review absorbing states and closed classes.
- Review periodicity or cyclic behavior.
- Review whether the long-run horizon is operationally meaningful.
