# Advanced Long-Run Transition Review

- **stationary_vs_limiting** (required): Distinguish stationary distributions from actual limiting behavior.
- **initial_condition_sensitivity** (required): Compare different starting distributions to test path dependence.
- **convergence_speed** (required): Measure whether convergence occurs within a practical decision horizon.
- **closed_classes_absorption** (required): Review absorbing states and closed classes for lock-in or terminal outcomes.
- **periodicity** (recommended): Check whether cycles prevent simple convergence.
- **transition_rule_validity** (required): Review whether a fixed transition matrix remains valid over repeated steps.
