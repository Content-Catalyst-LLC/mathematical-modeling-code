# Network Adjacency Matrices

Companion code and reproducible workflows for **Network Adjacency Matrices** in the **Linear Algebra for Systems Modeling** series.

## Themes

- binary, weighted, directed, and undirected adjacency
- node and edge definitions
- degree, in-degree, out-degree
- matrix powers, walks, and reachability
- sparse representation
- normalization and transition matrices
- spectral network structure
- data provenance and governance

## Run

```bash
make smoke
make all
make calculators
make advanced
```
