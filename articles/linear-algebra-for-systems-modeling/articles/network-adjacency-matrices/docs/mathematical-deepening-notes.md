# Mathematical Deepening Notes

## Required distinctions

- node definition versus edge definition
- binary adjacency versus weighted adjacency
- directed versus undirected networks
- raw adjacency versus normalized transition structure
- dense matrix versus sparse graph representation
- walk counts versus simple paths
- degree versus influence
- observed zero versus missing edge

## Review checklist

- Define nodes and network boundary.
- Define edge meaning.
- Document direction convention.
- Document weight meaning and units.
- State diagonal convention and self-loop handling.
- Report shape, density, nonzero entries, and sparsity.
- Compute in-degree, out-degree, and weighted degree.
- Compute selected matrix powers for indirect pathways.
- Document normalization and transition-matrix construction.
- Review data provenance, missingness, stale data, and sensitivity.
