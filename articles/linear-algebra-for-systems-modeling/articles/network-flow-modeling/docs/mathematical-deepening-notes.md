# Mathematical Deepening Notes

## Required distinctions

- graph connectivity versus feasible flow
- source node versus sink node versus transshipment node
- edge capacity versus actual flow
- capacity slack versus saturated edge
- conservation versus storage, loss, delay, or transformation
- maximum flow versus minimum-cost flow
- minimum cut versus all possible bottlenecks
- shortest path versus costed unit flow
- single-commodity versus multi-commodity flow
- feasible solution versus desirable system outcome

## Review checklist

- Define what moves, units, and time scale.
- Define source, sink, demand, supply, and boundary.
- Document capacities, costs, and provenance.
- Build directed edge list and incidence matrix.
- Compute node balances and capacity slack.
- Identify saturated edges and possible bottlenecks.
- Test capacity, cost, demand, and edge perturbations.
- Document solver settings if optimization is used.
- Review equity, access, reliability, emissions, and burden tradeoffs.
