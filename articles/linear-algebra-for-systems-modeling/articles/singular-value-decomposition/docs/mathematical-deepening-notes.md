# Mathematical Deepening Notes

## Required distinctions

- SVD as a factorization versus SVD as an interpretive diagnostic
- exact rank versus numerical rank
- singular values versus eigenvalues
- dominant singular directions versus causes
- low-rank approximation versus faithful representation
- pseudoinverse recovery versus stable recovery
- explained energy versus decision relevance
- denoising versus deletion of weak but meaningful structure
- full SVD versus truncated or approximate SVD
- numerical stability versus model validity

## Review checklist

- Define matrix rows, columns, units, weights, and system meaning.
- Document centering, scaling, normalization, and missing-data handling.
- Report singular values, rank tolerance, numerical rank, and condition number.
- Report retained rank, explained energy, and reconstruction error.
- Review pseudoinverse threshold and noise amplification risk.
- Compare low-rank approximation against validation data and domain purpose.
- Interpret singular vectors as mathematical directions, not automatic causes.
