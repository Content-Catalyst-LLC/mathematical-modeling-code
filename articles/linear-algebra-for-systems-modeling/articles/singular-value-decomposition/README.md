# Singular Value Decomposition

Companion code and reproducible workflows for **Singular Value Decomposition** in the **Linear Algebra for Systems Modeling** series.

## Themes

- SVD factorization \(A = U \Sigma V^T\)
- singular values, left singular vectors, and right singular vectors
- rank, numerical rank, effective rank, and singular spectra
- condition numbers, weak directions, and numerical stability
- pseudoinverses and least-squares recovery
- low-rank approximation, compression, denoising, and truncation
- sparse, truncated, and large-scale SVD workflows
- dimensionality reduction and transition toward PCA
- decomposition governance and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
