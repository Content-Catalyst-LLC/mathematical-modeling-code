# Orthogonal Decomposition and Structured Approximation

Companion code and reproducible workflows for **Orthogonal Decomposition and Structured Approximation** in the **Linear Algebra for Systems Modeling** series.

## Themes

- orthogonal subspaces and complements
- projection matrices and residual geometry
- least-squares approximation
- orthogonal and orthonormal bases
- Gram-Schmidt and QR decomposition
- normal equations and numerical risk
- structured approximation and reduced models
- rank, conditioning, residual diagnostics, and approximation governance
- transition toward singular value decomposition

## Run

```bash
make smoke
make all
make calculators
make advanced
```
