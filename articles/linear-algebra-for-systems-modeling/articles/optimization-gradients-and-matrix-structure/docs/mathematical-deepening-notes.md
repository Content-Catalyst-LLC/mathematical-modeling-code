# Mathematical Deepening Notes

## Required distinctions

- objective function versus real-world goal
- decision vector versus actual decision authority
- constraint matrix versus full institutional context
- gradient direction versus moral or policy direction
- stationary point versus good solution
- local optimum versus global optimum
- numerical convergence versus valid interpretation
- optimized training loss versus deployment evidence
- model optimum versus causal truth

## Review checklist

- Define decision variables, objective function, constraints, data sources, and parameters.
- Document gradient formula, Hessian or curvature diagnostics, and solver method.
- Report step size, stopping criteria, objective history, and convergence status.
- Report conditioning, feature scaling, regularization, and solver stability.
- Compare iterative solution with stable baselines when possible.
- Run sensitivity tests for data, objective weights, constraints, and parameter assumptions.
- Interpret the optimum as a model result under assumptions.
