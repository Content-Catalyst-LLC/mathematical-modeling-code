# Optimization, Gradients, and Matrix Structure

Companion code and reproducible workflows for **Optimization, Gradients, and Matrix Structure** in the **Linear Algebra for Systems Modeling** series.

## Themes

- objective functions, decision vectors, and constraint matrices
- least squares, residuals, gradients, and matrix calculus
- gradient descent, Hessians, curvature, and convexity
- regularization, conditioning, numerical reliability, and solver diagnostics
- optimization in machine learning and systems modeling
- sensitivity testing and responsible interpretation of optimized outputs

## Run

```bash
make smoke
make all
make calculators
make advanced
```
