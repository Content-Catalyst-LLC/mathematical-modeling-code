# Graph Theory Foundations for Systems Modeling

Companion code and reproducible workflows for **Graph Theory Foundations for Systems Modeling** in the **Linear Algebra for Systems Modeling** series.

## Themes

- graphs, nodes, and edges
- directed, undirected, weighted, and bipartite graphs
- walks, paths, trails, and cycles
- connected components and reachability
- degree, local structure, and centrality
- trees, forests, and minimal connection
- adjacency, incidence, degree, transition, and Laplacian matrices
- shortest paths, cuts, bottlenecks, and flow
- graph algorithms and sparse computation
- graph-data provenance and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
