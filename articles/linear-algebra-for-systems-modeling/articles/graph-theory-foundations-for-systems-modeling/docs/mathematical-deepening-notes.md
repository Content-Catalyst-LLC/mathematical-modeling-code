# Mathematical Deepening Notes

## Required distinctions

- graph versus drawing
- node definition versus edge definition
- walk versus path versus trail
- cycle versus feedback interpretation
- connected component versus meaningful subsystem
- degree centrality versus substantive importance
- directed reachability versus undirected connectivity
- capacity weight versus cost weight
- graph metric versus system explanation
- sparse representation versus dense matrix representation

## Review checklist

- Define nodes, edges, graph type, boundary, and time period.
- Document direction conventions and weight semantics.
- Preserve edge-list provenance.
- Compute degree, weighted degree, and component summaries.
- Test reachability and shortest paths under the correct edge semantics.
- Identify cycles, bridges, and bottleneck structures where relevant.
- Construct adjacency, incidence, and Laplacian matrices where useful.
- Review centrality measures against the substantive question.
- Test sensitivity to missing edges, weight perturbation, and boundary changes.
