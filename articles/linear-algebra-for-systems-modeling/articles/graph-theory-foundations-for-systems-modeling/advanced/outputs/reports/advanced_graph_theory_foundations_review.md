# Advanced Graph Theory Foundations Review

- **node_definition** (required): Define graph nodes, node boundary, and units of analysis.
- **edge_definition** (required): Document what relationships produce graph edges.
- **graph_type** (required): State whether the graph is directed, undirected, weighted, bipartite, temporal, multilayer, or simplified.
- **weight_semantics** (required): Define whether weights represent distance, capacity, cost, frequency, probability, exposure, or similarity.
- **pathway_metrics** (recommended): Review walks, paths, cycles, components, reachability, and shortest paths.
- **centrality_metrics** (recommended): Choose centrality measures only when they match the systems question.
- **algorithmic_fit** (recommended): Align traversal, shortest path, flow, clustering, and ranking algorithms with graph semantics.
- **provenance_missingness** (required): Review source data, missing nodes, missing edges, false edges, stale weights, and measurement bias.
