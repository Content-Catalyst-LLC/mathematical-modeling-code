# Matrix Multiplication and Interaction Effects

Companion code and reproducible workflows for **Matrix Multiplication and Interaction Effects** in the **Linear Algebra for Systems Modeling** series.

## Themes

- matrix multiplication
- row-column products
- dot-product aggregation
- transformation composition
- noncommutativity
- associativity
- indirect effects
- interaction pathways
- adjacency powers
- state transitions
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
