# Scalars, Vectors, and System States

Companion code and reproducible workflows for **Scalars, Vectors, and System States** in the **Linear Algebra for Systems Modeling** series.

## Themes

- scalars as single quantities
- vectors as organized quantities
- system states
- component order and meaning
- units and scaling
- normalization review
- vector operations
- norms, distance, and similarity
- state change over time
- probability vectors
- feature vectors
- indicator vectors
- typed state records
- SQL assumption registries
- Canvas-ready governance artifacts
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
