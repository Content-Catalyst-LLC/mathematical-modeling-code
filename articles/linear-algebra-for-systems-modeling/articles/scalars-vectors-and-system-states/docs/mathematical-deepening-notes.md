# Mathematical Deepening Notes

## Required distinctions

- scalar versus vector
- vector component versus vector as a whole
- raw value versus scaled value
- component order versus component meaning
- state vector versus feature vector
- probability vector versus indicator vector
- Euclidean distance versus substantive difference
- magnitude versus interpretability
- normalized score versus physical unit
- computational array versus documented system state

## Review checklist

- Define every scalar and vector component.
- Record vector order and alignment with code arrays and matrices.
- Record units, scale, source, and measurement rules.
- Identify raw, normalized, standardized, indexed, and probability values.
- Avoid distance, similarity, norm, or magnitude claims before scaling review.
- Document time step, scenario, geography, population, and system boundary.
- Preserve warnings about omitted dimensions and incompatible comparisons.
- Treat the vector as a model representation, not a neutral list of numbers.
