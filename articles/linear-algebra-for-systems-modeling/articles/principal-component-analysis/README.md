# Principal Component Analysis

Companion code and reproducible workflows for **Principal Component Analysis** in the **Linear Algebra for Systems Modeling** series.

## Themes

- centered and standardized data matrices
- covariance matrices and variance maximization
- PCA as eigenvalue decomposition and SVD workflow
- scores, loadings, principal directions, and explained variance
- retained-rank selection, reconstruction, and residual diagnostics
- scaling, centering, outliers, robustness, and preprocessing sensitivity
- dimensionality reduction and reduced feature spaces
- PCA governance and responsible interpretation

## Run

```bash
make smoke
make all
make calculators
make advanced
```
