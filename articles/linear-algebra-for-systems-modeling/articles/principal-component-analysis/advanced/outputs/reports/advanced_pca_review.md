# Advanced Principal Component Analysis Review

- **data_matrix_construction** (required): Define observations, variables, entries, units, weights, and missing-data handling.
- **centering** (required): Document the baseline around which variation is measured.
- **scaling** (required): State whether PCA uses original units, standardization, normalization, or weights.
- **explained_variance** (required): Report component variance, cumulative variance, and retained-rank rationale.
- **scores_and_loadings** (required): Separate observation scores from variable loadings and document sign conventions.
- **residual_review** (required): Report reconstruction error and review observations or variables poorly represented by retained components.
- **outlier_review** (recommended): Review whether extreme observations are errors, rare cases, or important transitions.
- **validation_context** (required): Validate reduced representation against the specific systems question and downstream use.
