# Mathematical Deepening Notes

## Required distinctions

- raw data matrix versus centered data matrix
- covariance PCA versus correlation or standardized PCA
- principal directions versus component scores
- loadings versus scores
- explained variance versus decision importance
- retained components versus discarded residual structure
- PCA as SVD versus PCA as covariance eigenvalue problem
- dimensionality reduction versus causal explanation
- outliers as errors versus rare but meaningful cases
- visualization convenience versus full structure

## Review checklist

- Define observations, variables, units, and missing-data handling.
- Document centering, scaling, standardization, normalization, and transformations.
- Report explained variance, cumulative explained variance, retained rank, and reconstruction error.
- Export scores, loadings, residual diagnostics, and preprocessing metadata.
- Review outliers and subgroup representation.
- Validate PCA reduction against the actual systems question.
