# Incidence Structure and Graph Representation

Companion code and reproducible workflows for **Incidence Structure and Graph Representation** in the **Linear Algebra for Systems Modeling** series.

## Themes

- graphs as nodes and edges
- edge lists and graph representation choices
- unsigned and oriented incidence matrices
- sign conventions and direction conventions
- edge-flow vectors and node-balance equations
- flow conservation
- graph Laplacians from incidence matrices
- cuts, cycles, and structural subspaces
- sparse representation
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
