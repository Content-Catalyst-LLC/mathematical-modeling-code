# Mathematical Deepening Notes

## Required distinctions

- adjacency matrix versus incidence matrix
- unsigned incidence versus oriented incidence
- source-target convention versus sign convention
- edge list source format versus generated matrix format
- node balance versus edge flow
- conservation versus accumulation
- graph Laplacian versus adjacency matrix
- cut space versus cycle space
- dense matrix versus sparse matrix
- graph visualization versus auditable graph representation

## Review checklist

- Define nodes and graph boundary.
- Define edges and edge provenance.
- Document direction convention for every directed edge.
- Document sign convention for incidence entries.
- Construct unsigned and/or signed incidence matrices as needed.
- Compute node balances from edge flows.
- Derive unweighted or weighted graph Laplacians.
- Report rank and sparsity diagnostics.
- Review cut and cycle interpretation.
- Document conservation, source, sink, and storage assumptions.
