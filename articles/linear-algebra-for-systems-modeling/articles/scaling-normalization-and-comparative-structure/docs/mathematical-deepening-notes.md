# Mathematical Deepening Notes

## Required distinctions

- raw units versus transformed units
- centering versus standardization
- standardization versus normalization
- row normalization versus column normalization
- vector magnitude versus vector direction
- Euclidean distance versus cosine similarity
- covariance PCA versus correlation PCA
- numerical scaling versus interpretive scaling
- scale sensitivity versus numerical perturbation sensitivity

## Review checklist

- Document original units, transformation formula, comparison purpose, metric, and interpretation warning.
- Record row sums, column norms, means, standard deviations, ranges, outlier handling, and missing-value rules.
- Compare raw, centered, standardized, min-max, row-normalized, and unit-vector normalized representations when conclusions matter.
- Track how scaling affects norms, condition proxies, PCA, SVD, similarity, clustering, rankings, and solver behavior.
- Preserve scaling choices in notebooks, schemas, metadata, README files, output manifests, and generated reports.
