# Case Study: Infrastructure Interdependence

Companion code and reproducible workflows for **Case Study: Infrastructure Interdependence** in the **Linear Algebra for Systems Modeling** series.

## Themes

- dependency matrices, multilayer networks, coupling matrices, and service-level vectors
- cascading disruption, redundancy, robustness, criticality, and recovery leverage
- geography, time, capacity, uncertainty, data quality, and equity review
- scenario stress testing, sensitivity analysis, validation, and governance
- responsible interpretation of interdependence models as decision support, not prediction authority

## Run

```bash
make smoke
make all
make calculators
make advanced
```
