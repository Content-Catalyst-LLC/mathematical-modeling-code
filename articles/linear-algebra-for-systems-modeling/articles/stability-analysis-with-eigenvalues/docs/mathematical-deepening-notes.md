# Mathematical Deepening Notes

## Required distinctions

- discrete-time stability versus continuous-time stability
- spectral radius versus largest real part
- stable, unstable, and marginal modes
- asymptotic stability versus transient growth
- local stability versus global stability
- eigenvalue classification versus practical safety
- homogeneous system behavior versus forced response
- numerical stability versus substantive model validity
- stable system behavior versus desirable system behavior

## Review checklist

- State whether the model is discrete-time or continuous-time.
- Define the matrix and its units.
- Document scaling, time step, and reference state.
- Report eigenvalues.
- Report spectral radius for discrete-time analysis.
- Report largest real part for continuous-time analysis.
- Report eigenpair residuals and spectral gaps where computed.
- Review nonnormality and possible transient growth.
- Translate stability classification back into domain meaning.
