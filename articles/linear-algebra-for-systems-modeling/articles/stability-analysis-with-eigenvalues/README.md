# Stability Analysis with Eigenvalues

Companion code and reproducible workflows for **Stability Analysis with Eigenvalues** in the **Linear Algebra for Systems Modeling** series.

## Themes

- stability analysis
- eigenvalues
- spectral radius
- discrete-time systems
- continuous-time systems
- local linearization
- Jacobian matrices
- stable, unstable, and marginal modes
- damping and amplification
- oscillation
- transient growth
- numerical diagnostics
- calculator scaffolding

## Run

```bash
make smoke
make all
make calculators
make advanced
```
