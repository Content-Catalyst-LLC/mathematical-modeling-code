# When Linear Models Clarify and When They Distort

Companion code and reproducible workflows for **When Linear Models Clarify and When They Distort** in the **Linear Algebra for Systems Modeling** series.

## Themes

- linear approximation, additivity, proportionality, and superposition
- local linearization, model boundaries, and extrapolation risk
- residual diagnostics, curvature checks, misspecification, and validation
- interactions, thresholds, saturation, feedback loops, and regime shifts
- aggregation, average effects, subgroup review, and causal overclaiming
- responsible interpretation of linear models as structured approximations

## Run

```bash
make smoke
make all
make calculators
make advanced
```
