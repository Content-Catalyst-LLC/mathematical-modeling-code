# Linear Algebra for Systems Modeling: Notes

Linear algebra provides a formal language for representing structure, transformation, interdependence, dimensionality, and high-dimensional relationships.

## Core Modeling Questions

- What does each vector component represent?
- What does each matrix entry mean?
- Are variables measured on comparable scales?
- Is the matrix encoding correlation, causality, flow, constraint, transition, or adjacency?
- Is the system full rank, underdetermined, overdetermined, or ill-conditioned?
- Does dimensionality reduction preserve relevant structure?
- Are network relationships weighted, directed, observed, assumed, or inferred?

## Interpretation Cautions

- Matrix form can make assumptions look objective.
- Scaling can dominate results.
- Eigenstructure is formal structure, not automatic real-world explanation.
- PCA and SVD reveal mathematical variance, not necessarily causal meaning.
- Adjacency matrices can flatten relationship quality, direction, and timing.
