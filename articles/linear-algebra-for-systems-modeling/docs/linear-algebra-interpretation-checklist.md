# Linear Algebra Interpretation Checklist

## Representation
- Define vector components.
- Define matrix entries.
- Document units and scaling.
- State whether relationships are empirical, assumed, or theoretical.

## Computation
- Check rank and conditioning.
- Inspect eigenvalues carefully.
- Test sensitivity to scaling.
- Preserve matrix dimensions and labels.
- Record decomposition choices.

## Interpretation
- Avoid treating projections as complete reality.
- Avoid overinterpreting components.
- Distinguish correlation, transformation, flow, and causality.
- Explain what is gained and lost through reduction.
