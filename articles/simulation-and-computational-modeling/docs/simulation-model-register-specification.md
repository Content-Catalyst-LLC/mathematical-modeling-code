# Simulation Model Register Specification

## Article

**Simulation and Computational Modeling**

## Central claim

A simulation model is an executable mathematical model whose results depend on state definitions, update rules, numerical methods, input data, random processes, scenario design, and output metrics.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| component_type | state, update_rule, numerical_method, scenario_definition, stochastic_protocol, output_metric, validation_diagnostic |
| computational_structure | Formal or computational structure |
| interpretation | Plain-language meaning |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include update rules, time steps, solver settings, random seeds, scenario definitions, numerical approximations, verification checks, validation diagnostics, and decision-use outputs.
