# Ethics of Computational Modeling

Computational models can influence public policy, engineering design, health planning, environmental regulation, financial risk, emergency response, platform governance, and AI systems.

## Risks

- code hides assumptions behind technical authority;
- input data encode bias or missingness;
- parameter values embed contested assumptions;
- numerical methods introduce unreported artifacts;
- single-run simulations are treated as predictions;
- outputs imply false precision;
- exploratory scenarios become policy mandates;
- model workflows are not reproducible or auditable.

## Responsible practice

- document model structure and computational translation;
- verify implementation against the mathematical specification;
- validate outputs against purpose;
- publish code, inputs, settings, and outputs where appropriate;
- report uncertainty and sensitivity;
- state intended use and use limits clearly.
