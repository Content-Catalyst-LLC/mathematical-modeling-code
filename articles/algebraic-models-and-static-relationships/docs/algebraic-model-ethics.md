# Ethics of Algebraic Modeling

Algebraic models can make decisions appear cleaner than they are.

## Risks

- objective functions hide value judgments;
- ratios hide numerator or denominator effects;
- constraints encode political choices as technical facts;
- aggregate formulas hide subgroup variation;
- static approximations erase delay, history, and adaptation;
- simple formulas appear more authoritative than warranted.

## Responsible practice

- state objectives and weights;
- document denominators and reference scales;
- identify constraint sources;
- report scenario sensitivity;
- distinguish static conclusions from dynamic claims;
- communicate assumptions and use limits.
