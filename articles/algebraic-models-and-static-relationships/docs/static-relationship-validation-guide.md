# Static Relationship Validation Guide

## Core checks

- Is the formula serving a defined purpose?
- Are units dimensionally consistent?
- Is the valid domain stated?
- Are parameters estimated, calibrated, transferred, or assumed?
- Are constraints physical, legal, ethical, budgetary, or assumed?
- Are static conclusions being overextended into dynamic claims?

## Recommended artifacts

- relationship register;
- parameter table;
- unit and domain audit;
- scenario comparison;
- feasible-region diagnostics;
- sensitivity summary;
- use-limit note.
