# Algebraic Relationship Register Specification

## Article

**Algebraic Models and Static Relationships**

## Central claim

Algebraic relationships are not merely formulas. They are formal model claims about identities, balances, ratios, constraints, objectives, and static mappings.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| relationship_type | identity, balance, linear, nonlinear, ratio, objective, constraint, bounds |
| expression | Algebraic expression |
| interpretation | Plain-language meaning |
| domain_or_constraint | Valid domain, units, or constraint |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include objectives, constraints, ratios, nonlinear forms, fitted relationships, domain restrictions, and any relationship used for decision support.
