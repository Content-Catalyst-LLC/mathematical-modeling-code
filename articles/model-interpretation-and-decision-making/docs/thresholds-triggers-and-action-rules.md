# Thresholds, Triggers, and Action Rules

Thresholds turn model evidence into possible action. They are not purely technical.

## Review questions

- What threshold governs action?
- Who set the threshold and why?
- Could uncertainty cross the threshold?
- What happens if action is triggered incorrectly?
- What happens if action is not triggered when needed?
- Is human review required before action?

## Principle

A model can estimate distance to a threshold, but institutions own the threshold and the action rule.
