# Geometry Representation Guide

## Core checks

- Is the real-world object represented as a point, line, polygon, grid, surface, or network?
- What information does that representation preserve?
- What information does it discard?
- Does the geometry match the model purpose?
- Are coordinate systems, units, and projections documented?
- Do spatial layers align?
- Is the result sensitive to boundary or resolution choices?

## Principle

A spatial model is not accurate simply because it looks like a map. Geometry is an assumption.
