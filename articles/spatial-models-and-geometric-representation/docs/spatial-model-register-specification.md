# Spatial Model Register Specification

## Article

**Spatial Models and Geometric Representation**

## Central claim

A spatial model is a mathematical model whose conclusions depend on location, geometry, distance, boundary, scale, adjacency, surface, or spatial interaction.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| component_type | geometry, coordinate_system, distance_metric, accessibility_metric, neighborhood_rule, spatial_field, validation_diagnostic |
| geometry_or_structure | Formal or computational structure |
| interpretation | Plain-language meaning |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include coordinate reference systems, geometry choice, projection and units, distance metrics, accessibility formulas, boundary definitions, resolution, and uncertainty diagnostics.
