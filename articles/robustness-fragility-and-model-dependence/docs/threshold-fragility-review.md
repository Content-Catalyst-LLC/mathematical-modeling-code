# Threshold Fragility Review

Threshold fragility occurs when a small disturbance can reverse an action.

## Required questions

- What threshold governs action?
- How far is the model output from the threshold?
- Which model forms or scenarios cross the threshold?
- How small a disturbance reverses the conclusion?
- Who bears the consequence of threshold error?

## Principle

Average accuracy is insufficient when decisions depend on threshold crossing.
