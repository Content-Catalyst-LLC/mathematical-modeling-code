# Threshold Risk Communication

When decisions depend on thresholds, uncertainty communication must address action reversal.

## Required questions

- What threshold governs action?
- How close is the model output to that threshold?
- How often do plausible runs cross the threshold?
- What changes would reverse action?
- Who bears the consequences of being wrong?
- What monitoring trigger should update the model?

## Principle

Threshold uncertainty is decision-relevant uncertainty.
