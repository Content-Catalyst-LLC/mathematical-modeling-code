# Communication Ethics and Governance

Uncertainty communication has ethical stakes because model outputs can affect resource allocation, safety, health, infrastructure, environmental governance, and institutional accountability.

## Ethical risks

- false certainty;
- vague caveats;
- selective disclosure;
- technical exclusion;
- hidden value judgment;
- uneven risk burden;
- absent use limits.

## Responsible practice

- name uncertainty sources;
- label intervals and scenarios;
- explain threshold risk;
- disclose structural limits;
- separate evidence from value judgment;
- state use limits and update triggers.
