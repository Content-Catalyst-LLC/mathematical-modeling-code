# Uncertainty Communication Guide

## Article

**Communicating Model Uncertainty**

## Central claim

Model outputs are conditional claims. Responsible communication makes uncertainty, assumptions, limits, and decision relevance visible enough for proportionate judgment.

## Required records

| Record | Purpose |
|---|---|
| communication_review_queue | Tracks audience, message goal, plain-language statement, and priority |
| uncertainty_messages | Separates technical statement, plain-language statement, and decision relevance |
| uncertainty_communication_card | Combines audiences, messages, use limits, and diagnostic checks |
| use_limit_statement | Prevents outputs from traveling beyond evidence |
| audience_summary | Shows where communication priority is concentrated |
