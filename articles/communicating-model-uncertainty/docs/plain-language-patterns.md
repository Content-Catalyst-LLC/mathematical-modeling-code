# Plain-Language Patterns

Plain language should reduce confusion, not reduce truth.

## Weak

The model has uncertainty.

## Stronger

The largest uncertainty comes from future demand and recovery-rate estimates.

## Weak

Results may change.

## Stronger

The recommendation changes if extraction rises by about 10 percent.

## Weak

Use with caution.

## Stronger

This model supports risk comparison and monitoring, not automatic action outside the validated domain.
