# Generalization Ethics and Governance

Generalization claims authorize applying a model beyond the data used to build it.

## Ethical risks

- overclaiming accuracy;
- hiding overfitting behind strong training performance;
- ignoring uneven performance across groups or settings;
- extrapolating outside observed evidence;
- failing to monitor drift or distribution shift;
- using a model for decisions it was not assessed to support.

## Responsible practice

- state validation context;
- report training and validation error separately;
- assess subgroup, spatial, temporal, and scenario transfer when relevant;
- flag extrapolation;
- monitor and revalidate changing systems;
- publish use limits.
