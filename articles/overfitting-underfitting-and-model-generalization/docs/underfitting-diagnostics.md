# Underfitting Diagnostics

Underfitting occurs when a model is too simple, rigid, or wrongly structured to represent important system behavior.

## Warning signs

- high training error;
- high validation error;
- patterned residuals;
- poor threshold behavior;
- predictions are too smooth or flat;
- known mechanisms are missing.

## Responsible practice

- review model form and assumptions;
- add relevant variables or mechanisms;
- check scale and boundary choices;
- compare candidate model families;
- avoid equating simplicity with responsibility when important structure is omitted.
