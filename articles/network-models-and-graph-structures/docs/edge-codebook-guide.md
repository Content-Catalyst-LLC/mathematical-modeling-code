# Edge Codebook Guide

An edge codebook explains what every link means.

Core checks:

- What does an edge mean?
- Is the edge directed or undirected?
- Is the edge weighted or unweighted?
- Does the edge represent contact, dependency, flow, influence, similarity, transaction, or physical connection?
- How was the edge observed or inferred?
- What is the evidence quality for each edge?
- Are relationship types mixed in the same graph?
