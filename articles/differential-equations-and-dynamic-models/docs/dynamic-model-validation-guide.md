# Dynamic Model Validation Guide

## Validation should examine behavior

A dynamic model should not be validated only by final values. It should be evaluated by trajectory shape, timing, stress periods, equilibrium behavior, recovery behavior, and response to intervention.

## Review questions

- Does the model reproduce relevant observed trajectories?
- Are rates plausible?
- Are initial conditions credible?
- Are time scales consistent?
- Do parameter changes alter qualitative behavior?
- Is uncertainty visible across the time horizon?
- Are outputs interpreted as conditional trajectories rather than guaranteed futures?
