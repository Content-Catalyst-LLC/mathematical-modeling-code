# Dynamic Model Register Specification

## Article

**Differential Equations and Dynamic Models**

## Central claim

Differential equations are structured claims about how state variables change through rates, flows, feedback, inputs, parameters, and time.

## Required fields

| Field | Purpose |
|---|---|
| key | Stable identifier |
| component_type | state variable, rate equation, initial condition, boundary condition, parameter, numerical setting, output diagnostic |
| expression | Mathematical or computational expression |
| interpretation | Plain-language meaning |
| units_or_domain | Units, dimensional requirement, or domain |
| review_question | Review question |
| status | active, review, revise, or archive |

## High-priority records

High-priority records include rate equations, boundary conditions, initial conditions, solver settings, time steps, calibration parameters, and outputs used for decision support.
