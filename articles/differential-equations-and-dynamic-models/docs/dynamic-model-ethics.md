# Ethics of Dynamic Modeling

Dynamic models can influence decisions about timing, futures, intervention, risk, and resource allocation.

## Risks

- long-term harms hidden by short horizons;
- historical disadvantage treated as neutral initial condition;
- omitted feedback hides policy resistance;
- aggregate trajectories hide unequal local impacts;
- precise-looking paths create false forecast confidence;
- simulation output substitutes for judgment.

## Responsible practice

- report multiple horizons;
- document initial conditions;
- review feedback loops;
- disaggregate where impacts differ;
- communicate uncertainty bands or scenarios;
- frame outputs as conditional trajectories.
