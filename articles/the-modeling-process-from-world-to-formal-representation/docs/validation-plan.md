# Validation Plan

## Validation question

Does the reservoir stock-flow model represent storage behavior adequately for its intended demonstration purpose?

## Evidence currently included

- Synthetic observed-storage sample.
- Scenario definitions.
- Assumption register.
- Generated storage and shortage-risk outputs.

## Required before operational use

1. Historical storage observations.
2. Inflow records.
3. Demand records.
4. Evaporation and loss estimates.
5. Capacity and operating rules.
6. Independent validation period.
7. Residual diagnostics.
8. Sensitivity analysis.
9. Uncertainty propagation.
10. Stakeholder/domain expert review.
