# Structural Validation Plan

## Validation question

Is the chosen mathematical structure adequate for the intended use?

## Structural tests

- compare linear and nonlinear forms;
- compare constrained and unconstrained dynamics;
- test boundary behavior at extremes;
- test whether feedback changes conclusions;
- test stochastic variation or scenario ranges;
- check unit and domain consistency;
- validate structure against evidence and mechanism;
- document where structure should not be used.

## Output artifacts

- relationship register;
- structural comparison table;
- sensitivity and stress-test outputs;
- prohibited-use statement;
- structural revision log.
