# Structural Taxonomy

## Linear

Assumes proportional response over the modeled range.

## Nonlinear

Allows response to change with scale, state, or regime.

## Static

Maps inputs to outputs without explicit time evolution.

## Dynamic

Updates state over time through recurrence, difference, or differential equations.

## Deterministic

Produces the same output for the same inputs and parameters.

## Stochastic

Represents uncertainty, variability, or random process behavior.

## Feedback

Allows system output or state to influence future input or state.

## Constraint

Defines feasibility, domain, conservation, capacity, budget, safety, or ethical limits.

## Networked

Represents interaction across connected units.

## Optimization

Represents choice through objective functions and feasible sets.
