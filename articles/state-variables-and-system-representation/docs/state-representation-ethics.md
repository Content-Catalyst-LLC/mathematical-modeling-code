# Ethics of State Representation

State representation determines what a model remembers and forgets.

## Risks

- aggregate state hides subgroup or local differences;
- memoryless state omits accumulated burden;
- proxy state is treated as true condition;
- institutional capacity is omitted;
- hidden state is inferred with false confidence;
- decision-state reduction defines people or systems only by model variables.

## Responsible practice

- document state omissions;
- distinguish state, input, output, parameter, and diagnostic roles;
- represent backlog, exposure, depletion, or cumulative harm where relevant;
- state proxy limits and uncertainty;
- use disaggregated state where decisions affect groups differently.
