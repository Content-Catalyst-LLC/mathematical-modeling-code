# Observability and Hidden State

A state variable may be directly observed, partially observed, proxy observed, or hidden.

## Directly observed

Measured with reasonable reliability.

## Partially observed

Observed through samples, intervals, or incomplete data.

## Proxy observed

Represented by an index, score, sensor proxy, or indirect measurement.

## Hidden

Inferred through model structure or statistical estimation.

## Review questions

- Can the state be measured?
- Does the measurement match the state concept?
- Is observation delayed or noisy?
- Can the hidden state be identified from available data?
- Are proxy limits communicated?
