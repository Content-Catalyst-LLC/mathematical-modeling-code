# Scale and Resolution Notes

## Scale dimensions

- temporal scale;
- spatial scale;
- population scale;
- mechanism scale;
- organizational scale;
- computational resolution.

## Scale review questions

- Does the scale of representation match the scale of the question?
- Does output resolution exceed input data quality?
- Are local extremes hidden by regional averages?
- Are long-term effects hidden by short horizons?
- Are subgroup effects hidden by aggregation?
- Does solver or grid resolution create numerical artifacts?

## False resolution

A model can produce detailed outputs even when the underlying data, assumptions, or mechanisms are coarse. Resolution should never be mistaken for certainty.
