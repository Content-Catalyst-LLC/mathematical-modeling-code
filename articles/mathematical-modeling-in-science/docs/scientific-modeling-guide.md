# Scientific Modeling Guide

## Article

**Mathematical Modeling in Science**

## Central claim

Scientific models are conditional representations that connect theory, evidence, mechanism, uncertainty, and prediction.

## Required artifacts

| Artifact | Purpose |
|---|---|
| scientific_model_register | Tracks domain, role, model family, evidence question, and status |
| population_scenario_summary | Compares scientific scenario outputs |
| baseline_population_trajectory | Provides a reproducible example trajectory |
| scientific_model_evidence_card | Summarizes evidence, use limits, and diagnostics |
| validation_domain_note | Prevents scientific claims from traveling beyond evidence |
