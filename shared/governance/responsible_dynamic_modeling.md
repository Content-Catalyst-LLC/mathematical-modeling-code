# Responsible Dynamic Modeling

Differential equation models should be used as explicit representations of proposed dynamic mechanisms, not as automatic truth.

## Guardrails

- Define state variables clearly.
- Document parameters and units.
- State initial and boundary conditions.
- Explain solver choice and time step.
- Test sensitivity to parameters and numerical settings.
- Distinguish qualitative insight from predictive accuracy.
- Avoid overclaiming causal or empirical validity without evidence.
