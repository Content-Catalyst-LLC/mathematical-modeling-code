# Responsible Linear Algebra Modeling

Linear algebra models should represent structure transparently and avoid treating compact matrix form as automatic explanation.

## Guardrails

- Define vector components and matrix entries.
- Document scale, units, normalization, and basis choices.
- Distinguish correlation, transformation, flow, transition, and causality.
- Check rank, conditioning, and numerical stability.
- Explain what decompositions preserve and discard.
- Avoid overinterpreting latent components without domain support.
